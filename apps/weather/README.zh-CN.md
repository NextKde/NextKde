# KOS 天气

**[English](README.md) | [中文](README.zh-CN.md)**

KOS 天气是独立的 Qt Quick 预报应用。它与 Quickshell 天气组件读取同一份带
版本的服务快照，网络请求和缓存状态不归任何一个界面单独所有。

## 当前状态

应用已经接入第 1 版共享天气服务，可搜索并保存地点、切换公制/英制、手动
刷新，并展示当前天气、逐小时预报和七日预报。离线时继续显示最后一份完整
预报，过期数据会明确标记为缓存。

`kos-data-service` 是唯一负责联网和持久化的进程。Qt 客户端通过带版本的
`kos-data.sock` JSONL 接口发送命令、接收变更事件，并保留原子快照作为离线
回退；Quickshell 天气组件读取同一份协议。

## 构建

```bash
cmake --preset weather-dev
cmake --build --preset weather-dev
```

应用位于 `.build/weather-dev/apps/weather/`。同一 preset 会同时构建 Go 数据
服务，因此除 Qt 6 外还需要 Go 工具链。

## 已包含范围

- 本地化地点搜索和多个收藏地点。
- 当前天气、完整的剩余逐小时预报和最多七日预报，标题随实际天数变化。
- 城市删除、搜索加载/空结果/失败重试，以及空气质量中文等级和缺失数据提示。
- 公制/英制单位和手动刷新。
- 包含生成时间、过期时间的原子离线缓存。
- 通过 `kos-data-service` 与桌面天气组件共享状态。

第 1 版不包含雷达、灾害推送、自动定位和天气服务商账号同步。

## 运行服务

CMake 会把 `kos-data-service` 安装到所选前缀的 `libexec`。KOS 天气会复用已经
运行的核心服务；仅构建天气应用进行开发时，也可以按需启动已安装的服务。
完整应用安装器会启用 `kos-data.service`。服务或网络暂时不可用时，先前缓存的
预报仍会继续显示。

## 紧凑界面

界面按照 NextKde App Demo 紧凑桌面规格调整：侧栏 224 px，搜索和操作控件 28 px，城市条目 80 px，并收紧预报卡片。轻液态材质用于搜索和悬浮操作，天气场景与图表保留自身表现。窄窗口优先展示逐小时和逐日预报，再展示其他指标；减少透明度时控件使用实色。
