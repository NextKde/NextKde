## 本轮交付与验收

- [x] 左侧默认只显示工作、个人、运动；可分别显示/隐藏，日程和提醒事项共用分类与颜色。已有数据继续可见。

- [x] 编辑时可选择分类，保留已有 Todo 清单归属；日历分类不改写用户已有清单。
- [x] 点击事项打开详情：标题、类型、分类、时间、地点、备注、重复与提醒信息；可编辑，提醒事项可标记完成/未完成。

- [x] UI 遵循 nextkdeAppDemo：侧栏整块透明平面；顶部统一液态按钮和切换器；悬浮菜单/详情/下拉使用单层液态面板，内部条目不重复液态化；保持已确认的灰色选中态、黑色略粗切换文字和标题栏布局。
- [x] 中文界面、键盘入口、错误反馈与小窗口布局检查；不留下失效按钮。
- [x] 本机隔离数据完成新增/编辑/分类筛选/详情/完成状态与通知链路测试，检查编译和 QML 日志，展示正常数据环境中的最终日历。
