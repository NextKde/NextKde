# KOS 日历

**[English](README.md) | [中文](README.zh-CN.md)**

KOS 日历是独立的 Qt Quick 应用，不导入 Quickshell 运行时，也不依赖 `desktop/` 下的文件。

## 当前状态

应用现在可以独立构建和安装。参考 macOS 日历的布局提供月、周、日、年视图、迷你月历、搜索和日程列表，并支持全天/定时事件、重复规则预设、提醒以及 iCalendar 导入导出。提醒事项工作区中设置了日期的任务会与事件一同显示，并保留完成状态。带版本的 D-Bus PIM 服务负责 KCalendarCore 持久化和桌面通知，界面不会直接读写数据文件。

## 日历与待办联动

- 所有设置了截止日期的待办都会进入日历；重复待办由 PIM 服务按当前可见范围展开。
- 添加入口分为“日程”和“提醒事项”；提醒事项使用现有 Todo 后端。默认、工作、个人、家庭是日历分类，独立于 Todo 清单。
- 已有关联事件/任务仍可编辑、解除关联，并保留原目标清单和优先级；新建采用明确的两种入口。
- 关联后的标题、备注、日期时间、全天状态和可编辑的重复规则会双向同步；在提醒事项视图中完成任务后，日历会立即反映完成状态。
- 关联项目只由日历事件发送提醒，避免同一事项出现两次桌面通知。
- 删除任意一端或关闭关联时都会保留另一端，只解除关系，避免意外丢失数据。

## 构建

在仓库根目录执行：

```bash
cmake --preset calendar-dev
cmake --build --preset calendar-dev
```

可执行文件位于 `.build/calendar-dev/apps/calendar/`。

## 第一版边界

- 已包含：月/周/日视图、迷你月历、搜索、选中日期议程、事件增删改、带日期待办的显示与编辑、事件/任务关联、时区感知的本地存储、全天事件、重复规则预设、提醒、iCalendar 文件、键盘快捷键和屏幕阅读器标签。
- 暂缓：拖拽改期、时区选择界面、参会人调度、高级重复规则编辑、云账户、CalDAV。明确不接入 Akonadi。

日历和待办只共享 `Kos.Pim` 契约与服务，不互相导入应用代码。数据归属、兼容规则和安全限制见 `docs/PimArchitecture.md`。

## 紧凑界面

日历采用 nextkdeAppDemo 的 GalleryDesign 2.9：224px 普通侧栏、26px 液态工具栏
操作、28px 实色表单字段及紧凑弹窗底栏。月网格与选中日期日程使用平面内容材质；
日程高度随条目数量变化，较长列表在限定高度内滚动。周／日视图的初始位置和窗口
缩放都限制在有效滚动范围内。事件／任务编辑器保留原有校验和删除确认，公共底栏
只发出操作请求。

液态材质在共享 UI 边界显式接入。源码预览须使用重新构建、包含
`LiquidCompactSurface` 的日历二进制，旧版已安装程序无法加载这份源码。

## 材质对齐（nextkdeAppDemo）

日历直接使用 Demo 的 `LiquidActionButton`、`LiquidTextField`、
`LiquidSegmentedControl` 和 `LiquidSurface`，通过 `Kos.Demo` 模块接入。
`shared/demo-ui` 内的组件及着色器与 Demo 工作树逐字节一致，并记录 SHA-256。
独立模块避免改变其他应用正在使用的旧版 Kos.Ui。工具栏按钮采用最强液态档，搜索保留轻液态档，均使用紧凑尺寸。日历只管理布局、业务状态和采样来源，不额外叠加光圈、
染色、模糊层或自制按压回弹。原按钮遗留焦点环通过公开的 focusRingColor 属性
仅在液态档隐藏；普通回退保留语义焦点反馈。

侧栏采用独立 Sidebar Demo 的桌面透明模式：单层连续普通背景，不透明度 0.95，
文字完全不透明。侧栏下不再铺整窗实色底，右侧内容区保持不透明。该区域没有
窗口内背景场景可供模糊，因此不增加无效模糊或复制右侧页面。普通窗口透明合成
不会采样或模糊桌面，也不请求 KWin 液态效果。收起侧栏同步移除背景覆盖；实色、
减少透明度与软件渲染时回退为不透明。

菜单、详情、下拉选项和悬停提示使用一层原版液态表面与同窗 QML 底层模糊，
内部栏目和文字保持普通材质。编辑器弹层采样编辑器，排除自身。设置保持普通
不透明面板及普通分段选择器。“自动／玻璃”启用 QML 采样，“实色”和“减少
透明度”停止采样。不透明度相对默认值 0.86 调节原组件填充 token（默认仍为 Demo
的 0.35），浮层覆盖程度单独按相同比例调整，不降低文字透明度。

## 分类、详情与通知

左侧“我的日历”下列出默认、工作、个人、家庭，可分别显示/隐藏日程；“其他”下的“已安排的提醒事项”
独立控制待办显示，不受日历分类勾选影响。新日程归入“默认”，已有个人分类保持不变；
旧运动及未知分类在“默认”下显示，不改写原始元数据或已有 Todo 清单。侧栏不再显示“今天”，
工具栏的“今天”按钮和快捷键继续可用。
添加菜单提供日程和提醒事项。详情包含分类、时间、备注、重复/通知信息，提醒事项
可完成或恢复未完成。保存收到服务成功回复后才关闭；失败保留表单。修改普通字段
不会覆盖现有自定义重复规则和提醒偏移。

点击通知通过 `--item event:<uid>` 或 `--item todo:<uid>` 打开对应详情；日历未运行
时自动启动。提醒事项通知另提供“标记完成”。支持转发桌面激活令牌，关闭通知后
清理其标识。通知需要 PIM 服务运行，通知服务器需支持动作；本轮不自动安装后台
开机启动策略。完整验收与后续清单见 [迭代计划](ITERATION_PLAN.zh-CN.md)。

## 节假日日历

默认不添加任何地区的节假日。“其他”先显示“已安排的提醒事项”和
“添加节假日日历…”入口，添加成功后才显示该来源的名称。

- 国家或地区：选择中国、美国、英国、日本、德国、法国、澳大利亚或加拿大，
  应用自动获取 Apple 公共节假日日历。首次添加需要联网，无需寻找文件。
- 自定义：填写 HTTP(S)/webcal 订阅地址，或选择本地 `.ics` 文件导入。
- 可添加多个来源，每个来源独立勾选显示，通过右侧菜单刷新或移除。
- 在线来源在 PIM 服务运行时每日检查更新；离线或更新失败仍保留上次数据。
  文件来源通过“刷新”重新读取原文件，不会联网。
- 节假日详情可查看但不可逐条编辑；移除来源不会影响个人日程或提醒事项。
  来源事件使用独立 UID，保留日期和重复规则，忽略待办并清除通知提醒。

这些订阅由外部提供方维护，日期覆盖范围及更新进度取决于来源；中国节假日
订阅不作为法定调休／补班安排的保证。旧版导入的节假日保留为“已导入的节假日”。

“我的日历”标题旁的＋可添加分类；每行 …（或右键）打开通用带箭头 LiquidPopover，可修改名称、颜色及删除。默认日历保留为迁移目标，不能删除。删除前确认，其中的日程及提醒事项移到默认，不删除内容。分类由 PIM 服务持久化，和 Todo 任务清单独立。节假日 … 同样使用 LiquidPopover。

### 日历颜色

七色预设参考旧版 Apple 日历：红 #FB0055、橙 #FB8208、黄 #FEC309、绿 #56D72B、
蓝 #1D9BF6、紫 #BF57DA、棕 #90714C。
来源：[OS X El Capitan 10.11.3 实机记录](https://matt-stone.co.uk/change-colours-microsoft-office-365-shared-calendars-apple-calendar-os-x/)。
这不是已核验的 macOS 15/27 色值；[Apple 官方指南](https://support.apple.com/guide/calendar/icl1030/mac)
确认支持预设色和自定义颜色，但未列精确色值。默认／工作／个人／家庭对应紫／橙／蓝／绿，
属于本应用的默认分配。新建与编辑使用 18 个预设色，不提供色值输入或取色窗口；已有颜色保留。
仅升级未编辑过的旧初始色，保留已标记自定义色以及改名分类的原色。

### 锚定编辑与拖选

顶部＋直接打开创建表单；提醒事项工作区只创建提醒事项。新建、详情、编辑统一使用带箭头的
LiquidContentPopover，不压暗日历。新建可切换日程／提醒事项，两份草稿分别保留；
已有记录不通过标签转换类型。日期／重复／通知选项可展开，内部使用普通分组材质。
保存明确提交；点击外部或 Escape 关闭当前草稿，不自动保存。

周／日视图支持空白时间格纵向拖选，15 分钟步长、正反方向、边缘滚动，松手后
带入起止时间并锚定到范围。已有日程块仍打开详情，键盘 Return 创建仍保留。
本次不含月视图跨日拖选，也不含拖动已有日程改期。
不提供自然语言快速创建。明确授权的图形会话可执行 `python3 apps/calendar/tests/run-popover-review.py`，
使用隔离会话总线和临时 PIM 数据验证，不改用户记录。


## 日历与提醒事项合并（2026-10-28）

- 一个 `kos-calendar` 窗口，共用一个 PIM 客户端。侧栏顶部切换“日历／提醒事项”；侧栏收起时切换器位于工具栏，`Ctrl+Tab` 也可切换。
- 日历保留当前日期与日／周／月／年视图；提醒事项保留当前清单和筛选，两个工作区各自保留搜索词。
- 提醒事项提供全部、今天、已安排、已完成、清单筛选，搜索覆盖所有任务的标题与备注，包括没有日期的任务。
- 新建、查看、编辑均复用液态 Popover。支持清单归属、日期、完成状态、优先级、重复与提醒；编辑其他字段保留导入的自定义重复规则。
- 清单可新建、改名、移除；收件箱不能移除。移除清单将任务移入收件箱，不删除任务。
- `--view reminders` 打开提醒事项；旧 `kos-todo` 命令转发到同一日历实例，旧应用菜单入口隐藏。既有 PIM 数据不复制、不迁移。
- 本轮运行与图形检查只在虚拟机进行，使用临时 PIM 数据和独立 D-Bus 会话。

### 提醒事项组织

待办只归属一个清单；标旗与优先级独立。“已标旗”汇总所有清单中未完成的标旗任务。
行尾加号通过统一编辑 Popover 新建同清单子任务；清单视图支持展开／收起，日期和搜索
视图独立显示匹配任务。父子任务完成状态独立；移动父任务时同步移动子任务，删除父任务
时保留子任务并提升为顶层。PIM 服务拒绝循环父子关系。继续复用普通控件和共享液态 Popover。

### 分组、分区、标签和智能清单

- 左侧“我的清单”旁的＋可新建清单或群组。群组独立保存，空群组保留。点击名称查看组内清单汇总，点击箭头仅展开／收起。群组菜单支持改名、移除；移除后保留清单和任务。清单编辑器通过群组下拉选择移动归属，不再输入群组名称。
- 待办的“分区”用于组织清单正文；子任务跟随父任务分区。“标签”用空格或逗号分隔，可以带 `#`。侧栏标签跨清单筛选；标签采用标准 iCalendar Categories 保存。
- 新建清单时把“类型”改为“智能清单”，可以组合来源、标签、日期、标旗和优先级，条件为“同时满足”，仅匹配未完成待办。智能清单不拥有独立任务；从这里新建待办会带入条件，删除智能清单只删除筛选视图。已有清单不能更改类型。
- 从任务行的拖动柄拖到另一行上半部／下半部可前移／后移；拖到左侧普通清单可移动归属。普通清单允许排序，日期／搜索／智能清单保持计算顺序，但可以从中拖出移动归属。拖到同级行时采用目标的父任务和分区；服务拒绝循环嵌套。拖到侧栏清单会提升为顶层，父任务移动时携带子任务。
- 群组、分区和清单视图模式独立保存在元数据；旧群组／分区名称自动迁移。分区支持空记录、改名、排序、折叠与移除，移除后任务归到“其他”。任务分区、标旗、顺序仍保留兼容的 iCalendar 字段。

隔离图形验收（只在获准的环境执行）：
`KOS_CALENDAR_REVIEW_FIXTURE=ReminderOrganization.qml.inc python apps/calendar/tests/run-popover-review.py`
该脚本使用临时数据，覆盖分组、智能清单创建、标签、父子层级、真实鼠标拖放和深浅色布局。

### 紧凑清单与提醒事项详情

清单编辑提供 18 个预设色和 18 个通用矢量图标，不再要求输入 HEX／RGB。已有颜色保留。
侧栏清单使用 18px 色底图标、12px 文字，紧凑行高并保持垂直居中。

编辑提醒事项使用通用 SettingsGroup／SettingsItem：标题备注、日期时间、归属标签和任务属性。
打开时间开关即可选择小时／分钟；没有日期时自动填入今天。标签按需展开，可输入或点选，再次点击取消。“链接”支持 HTTP／HTTPS；
“添加图片”使用本机文件选择器，支持缩略图、移除和通过系统查看器打开。详情页同步显示
标签、链接入口和图片。

最多 8 张 PNG／JPEG／WebP／GIF／BMP 图片，每张不超过 10MB 和 2500 万像素。保存时实际
解码校验，并复制到 PIM 数据目录，移动原文件不影响已保存的提醒事项。移除附件只移除引用，
图片存储保守保留以兼容共享引用和备份；这些本地引用不是可跨设备携带的云附件。链接使用标准 iCalendar URL 字段。

### 清单内操作与分栏

- 点击分区末尾的空白行输入标题，回车保存并继续新增，空标题不保存、Escape 取消。任务自动归属当前清单与分区，不再有主体顶部的独立输入框。
- 任务标题可就地编辑；完成圆圈与右侧详情入口独立。详情入口打开锚定 Popover，编辑时不显示类型切换。右键任务可添加子任务或切换标旗。
- 普通清单内容区右键 → 添加分区，也可使用标题下方“添加分区”。分区菜单可改名、上移、下移和移除；删除确认明确说明保留任务。
- 清单支持列表／分栏切换并保存选择。每列对应同一清单的一个分区；窄窗口横向滚动。群组汇总不使用分栏。
- 日期、智能筛选和搜索视图维持计算顺序；普通清单拖动可跨分区或移动到左侧清单。
