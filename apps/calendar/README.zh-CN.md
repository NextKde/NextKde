# KOS 日历

**[English](README.md) | [中文](README.zh-CN.md)**

KOS 日历是独立的 Qt Quick 应用，不导入 Quickshell 运行时，也不依赖 `desktop/` 下的文件。

## 当前状态

应用现在可以独立构建和安装。参考 macOS 日历的布局提供月、周、日、年视图、迷你月历、搜索和日程列表，并支持全天/定时事件、重复规则预设、提醒以及 iCalendar 导入导出。KOS 待办中设置了日期的任务会与事件一同显示，并保留完成状态。带版本的 D-Bus PIM 服务负责 KCalendarCore 持久化和桌面通知，界面不会直接读写数据文件。

## 日历与待办联动

- 所有设置了截止日期的待办都会进入日历；重复待办由 PIM 服务按当前可见范围展开。
- 添加入口分为“日程”和“提醒事项”；提醒事项使用现有 Todo 后端。工作、个人、运动是日历分类，独立于 Todo 清单。
- 已有关联事件/任务仍可编辑、解除关联，并保留原目标清单和优先级；新建采用明确的两种入口。
- 关联后的标题、备注、日期时间、全天状态和可编辑的重复规则会双向同步；在 Todo 中完成任务后，日历会立即反映完成状态。
- 关联项目只由日历事件发送提醒，避免同一事项出现两次桌面通知。
- 删除任意一端或关闭关联时都会保留另一端，只解除关系，避免意外丢失数据。

## 构建

在仓库根目录执行：

```bash
cmake --preset calendar-dev
cmake --build --preset calendar-dev
```

可执行文件位于 `.build/calendar-dev/apps/calendar/`。

## 第一版边界

- 已包含：月/周/日视图、迷你月历、搜索、选中日期议程、事件增删改、带日期待办的显示与编辑、事件/任务关联、时区感知的本地存储、全天事件、重复规则预设、提醒、iCalendar 文件、键盘快捷键和屏幕阅读器标签。
- 暂缓：拖拽改期、时区选择界面、参会人调度、高级重复规则编辑、云账户、CalDAV。明确不接入 Akonadi。

日历和待办只共享 `Kos.Pim` 契约与服务，不互相导入应用代码。数据归属、兼容规则和安全限制见 `docs/PimArchitecture.md`。

## 紧凑界面

日历采用 nextkdeAppDemo 的 GalleryDesign 2.9：224px 普通侧栏、26px 液态工具栏
操作、28px 实色表单字段及紧凑弹窗底栏。月网格与选中日期日程使用平面内容材质；
日程高度随条目数量变化，较长列表在限定高度内滚动。周／日视图的初始位置和窗口
缩放都限制在有效滚动范围内。事件／任务编辑器保留原有校验和删除确认，公共底栏
只发出操作请求。

液态材质在共享 UI 边界显式接入。源码预览须使用重新构建、包含
`LiquidCompactSurface` 的日历二进制，旧版已安装程序无法加载这份源码。

## 材质对齐（nextkdeAppDemo）

日历直接使用 Demo 的 `LiquidActionButton`、`LiquidTextField`、
`LiquidSegmentedControl` 和 `LiquidSurface`，通过 `Kos.Demo` 模块接入。
`shared/demo-ui` 内的组件及着色器与 Demo 工作树逐字节一致，并记录 SHA-256。
独立模块避免改变其他应用正在使用的旧版 Kos.Ui。工具栏按钮采用最强液态档，搜索保留轻液态档，均使用紧凑尺寸。日历只管理布局、业务状态和采样来源，不额外叠加光圈、
染色、模糊层或自制按压回弹。原按钮遗留焦点环通过公开的 focusRingColor 属性
仅在液态档隐藏；普通回退保留语义焦点反馈。

侧栏采用独立 Sidebar Demo 的桌面透明模式：单层连续普通背景，不透明度 0.95，
文字完全不透明。侧栏下不再铺整窗实色底，右侧内容区保持不透明。该区域没有
窗口内背景场景可供模糊，因此不增加无效模糊或复制右侧页面。普通窗口透明合成
不会采样或模糊桌面，也不请求 KWin 液态效果。收起侧栏同步移除背景覆盖；实色、
减少透明度与软件渲染时回退为不透明。

菜单、详情、下拉选项和悬停提示使用一层原版液态表面与同窗 QML 底层模糊，
内部栏目和文字保持普通材质。编辑器弹层采样编辑器，排除自身。设置保持普通
不透明面板及普通分段选择器。“自动／玻璃”启用 QML 采样，“实色”和“减少
透明度”停止采样。不透明度相对默认值 0.86 调节原组件填充 token（默认仍为 Demo
的 0.35），浮层覆盖程度单独按相同比例调整，不降低文字透明度。

## 分类、详情与通知

左侧只列出工作、个人、运动三个默认分类，可分别显示/隐藏。日程与提醒事项共用
分类颜色；缺失或未知分类归入“个人”显示，但不改写原始元数据或已有 Todo 清单。
添加菜单提供日程和提醒事项。详情包含分类、时间、备注、重复/通知信息，提醒事项
可完成或恢复未完成。保存收到服务成功回复后才关闭；失败保留表单。修改普通字段
不会覆盖现有自定义重复规则和提醒偏移。

点击通知通过 `--item event:<uid>` 或 `--item todo:<uid>` 打开对应详情；日历未运行
时自动启动。提醒事项通知另提供“标记完成”。支持转发桌面激活令牌，关闭通知后
清理其标识。通知需要 PIM 服务运行，通知服务器需支持动作；本轮不自动安装后台
开机启动策略。完整验收与后续清单见 [迭代计划](ITERATION_PLAN.zh-CN.md)。
