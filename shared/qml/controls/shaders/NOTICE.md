# Compact material provenance

The compact surface, convex, diffuse and highlight GLSL/QSB pairs were imported
from the NextKde `nextkdeAppDemo` working snapshot on 2026-10-26. The source
retains NextKde ownership and the repository GPL-3.0 license. The original
`liquid_surface` pair is stored here as `liquid_compact_surface`.

The native convex-bezel profile was independently derived in QML/GLSL after
reviewing mkj0kjay/vue-web-liquid-glass revision
934404c05167417945e73a36388c20cc201b5a55 (its README declares MIT), specifically
the convex-squircle/Snell model and specular demonstration. No Vue framework,
displacement-map implementation or website assets were copied.
