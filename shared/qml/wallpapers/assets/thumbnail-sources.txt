themes/starfield/assets/preview.png and themes/weather/assets/preview.png are actual ThemeWallpaperScene.qml
frames exported at phase 6, default clear daytime weather, economical=false,
particleCount=80, with no widgets or pointer interaction. Output size: 960x540.
Weather changes and animation phase can change the live wallpaper's appearance.

Exporter: tools/assets/export-theme-thumbnails.cpp (Qt 6 Quick, QML, Gui).
Build from the repository root:
  mkdir -p .build/theme-thumbnail-export
  g++ -std=c++17 -fPIC tools/assets/export-theme-thumbnails.cpp -o .build/theme-thumbnail-export/export $(pkg-config --cflags --libs Qt6Quick Qt6Qml Qt6Gui)
Run in an existing graphical session, one theme per process (shows a brief window):
  QSG_RHI_BACKEND=opengl .build/theme-thumbnail-export/export "$PWD/shared/qml/wallpapers/ThemeWallpaperScene.qml" starfield "$PWD/shared/qml/wallpapers/themes/starfield/assets/preview.png"
  QSG_RHI_BACKEND=opengl .build/theme-thumbnail-export/export "$PWD/shared/qml/wallpapers/ThemeWallpaperScene.qml" weather "$PWD/shared/qml/wallpapers/themes/weather/assets/preview.png"

Settings and preview grids load these PNG files only. The exporter and desktop
renderer are never instantiated by a thumbnail delegate.
