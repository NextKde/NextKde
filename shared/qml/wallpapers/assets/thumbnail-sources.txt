OpticalScene collection — runtime procedural scenes

The five built-ins use OpticalScene.qml and the aurora, prism, ocean and lagoon
fragment shaders in the parent wallpapers module. Runtime scenes no longer load
baked plates or motion masks. Their texture long edge is capped at 1280 pixels
normally or 800 pixels when host.economical is true; this is a size limit, not a
measured performance claim. Rebuild shader binaries with compile.sh after changes.

Stable IDs and current scenes:
starfield = Polar Aurora (aurora, variant 0)
blackhole = Studio Crystal (prism, variant 0)
weather = Golden Ocean (ocean, variant 0)
underwater = Crystal Lagoon (lagoon, variant 0)
forest = Moonlit Ocean (ocean, variant 1)
The weather ID is retained for compatibility and is not driven by live weather.
