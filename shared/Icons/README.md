# Shared interface icons

This is the Kos.Icons runtime snapshot from NextKde/nextkdeAppDemo commit `86a9c66008ea8395fedb2bc613992a5a3d8389e8`, path `shared/Icons`. Keep this module identical across applications; it contains the pinned Framework7 font and NextKde extensions.

Canonical editable sources, update instructions and the VM-only font tests are in [nextkdeAppDemo](https://github.com/NextKde/nextkdeAppDemo/tree/86a9c66008ea8395fedb2bc613992a5a3d8389e8/tools/icons) and its `docs/Icons.md`. Update the font, mapping and provenance together. Application logos and user artwork stay separate from interface glyphs.
