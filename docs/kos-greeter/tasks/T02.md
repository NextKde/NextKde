## 执行细化

从独立的最小 Greeter 入口开始，只有默认图片、用户名与认证提示；不加载现有 desktop Shell。固定 greetd 的 initial/default session 与 KWin `--exit-with-session` 的原型命令，在隔离环境记录实际 argv、seat、VT和进程关系。启动命令必须来自已安装会话的允许清单。

状态至少覆盖 Idle、Authenticating、AwaitingPrompt、ReadyToLaunch、Exiting、LaunchRequested、Terminated。每条提示按是否secret选择输入形式；取消调用对应会话取消操作，错误后允许新认证而不复用旧secret。ReadyToLaunch后执行占位退场，再提交launch，收到确认后结束前端。人为延迟前端退出，验证用户会话等待行为；解除延迟后应正常启动。

错误注入包括错误密码、取消提示、greetd连接中断、前端异常退出、用户会话立即失败。每项保存脱敏状态日志与完整进程树，恢复到登录或TTY。没有证明TTY和旧管理器可恢复，不能进入实机集成。
