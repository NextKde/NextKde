# T11 桌面就绪门控与揭幕

状态：阻断（实现及隔离验证已交付；完整 A03/A10、冷热启动录像未测，独立复审通过）。负责人：主代理。阶段：用户于2026-10-12明确授权实施。

## 目标

正式背景和必要bar/Dock统一显露。

## 依赖与开始条件

T08,T10。依赖交付物须可复查；失败或未测不能冒充满足。

## 范围

资源/窗口/帧/essential ready分层。

## 具体步骤

1. 加入会话入场门槛。
2. 抑制一次top切换。
3. 对齐资源hash/crop。
4. 不等天气。
5. 超时处理。
6. 记录全时间线。

## 交付物

ready协议、组件门控、冷热启动录像。记录提交、组件版本和证据相对路径。

## 验收

A03/A10，无提前弹出或第二次壁纸切换。按 [验收矩阵](../acceptance.md) 与 [证据模板](../evidence/TEMPLATE.md)逐项填写。未测保留未测；证据缺失不得关闭任务。

## 失败回退

超时撤罩，保留可用桌面。记录触发条件、恢复命令/操作、耗时与最终状态；失败场景必须可重复。

## 非目标

等待所有后台数据。不扩大认证权限、不顺带重构无关模块。

## 约束与评审

遵守 [硬约束](../constraints.md) 与 [AGENTS.md](../AGENTS.md)。存在证据冲突时暂停依赖动作，先澄清事实；普通原型不授权系统服务切换。

## 执行细化

扩展现有WallpaperService就绪信息时保持资源ready和帧ready分层。正式壁纸提交事件必须带session、output和hash，Cover只接受匹配事件；多个输出允许各自准备，但统一揭幕策略要明确超时屏如何处理。

为顶部栏、Dock增加会话入场门槛的方案，正常日常显示逻辑仍独立工作。必要状态定义限定配置/几何/窗口映射，不包含天气/音乐/应用索引完整加载。登录交接flag仅抑制一次wallpaper top切换，消费后清除。

门槛满足后启动Cover渐隐与桌面元素显露的统一时间轴；记录RevealStarted/RevealComplete。延迟一个组件、丢失ready、hash不匹配、重复旧事件分别注入；最后必须超时恢复到可操作桌面，而不是永久等待。

## 完成后的独立子代理审查

每次完成本卡工作，先标记待独立审查，必须调用未参与本卡编写或实现的独立子代理审查当前产物、相关约束和验收证据。执行者修复后交独立代理复审；P0/P1/P2关闭后才能标记完成，P3须记录处置并经审查确认。保存被审版本、代理ID、问题及复审结论。不得用作者自查替代。详见 [独立审查规则](../REVIEW_POLICY.md)，填写 [证据模板](../evidence/TEMPLATE.md)。
