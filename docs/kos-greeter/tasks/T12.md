# T12 动态与空间壁纸回退

状态：阻断（实现及隔离验证已交付；独立复审通过，完整验收受 T11/实机证据阻断）。负责人：Codex。阶段：用户于2026-10-12明确授权完成本卡，当前分支实施。

## 目标

可信动态背景状态继承或安全静态接点。

## 依赖与开始条件

T07,T10,T11。依赖交付物须可复查；失败或未测不能冒充满足。

## 范围

phase/背景专用snapshot/预生成空间素材。

## 具体步骤

1. 分类时间主题与GPU模拟。
2. 验证phase可复现性。
3. 捕获仅背景。
4. 空间中性视角。
5. 不可信QML静态化。
6. 性能预算。

## 交付物

主题支持表、回退资产与测试。记录提交、组件版本和证据相对路径。

## 验收

A12/A13，无法连续则明确回退。按 [验收矩阵](../acceptance.md) 与 [证据模板](../evidence/TEMPLATE.md)逐项填写。未测保留未测；证据缺失不得关闭任务。

## 失败回退

静态背景接点。记录触发条件、恢复命令/操作、耗时与最终状态；失败场景必须可重复。

## 非目标

登录时AI推理或任意主题执行。不扩大认证权限、不顺带重构无关模块。

## 约束与评审

遵守 [硬约束](../constraints.md) 与 [AGENTS.md](../AGENTS.md)。存在证据冲突时暂停依赖动作，先澄清事实；普通原型不授权系统服务切换。

## 执行细化

建立每个内置主题的能力表：时间函数可复现、随机种子可控制、GPU模拟需快照、空间素材需预生成。时间主题冻结结束相位并让桌面从同phase开始后恢复时钟；粒子主题对比多次重启证明是否能复现，不能只比较phase字段。snapshot必须来自背景离屏层，不包含头像/表单/用户窗口，并以同crop显示；缺图走静态默认。空间模式使用已有深度图与中性相机，禁止登录进程触发模型下载或推理。输出性能和内存预算，未知QML主题默认不运行。

## 完成后的独立子代理审查

每次完成本卡工作，先标记待独立审查，必须调用未参与本卡编写或实现的独立子代理审查当前产物、相关约束和验收证据。执行者修复后交独立代理复审；P0/P1/P2关闭后才能标记完成，P3须记录处置并经审查确认。保存被审版本、代理ID、问题及复审结论。不得用作者自查替代。详见 [独立审查规则](../REVIEW_POLICY.md)，填写 [证据模板](../evidence/TEMPLATE.md)。
