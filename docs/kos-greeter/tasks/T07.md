# T07 独立壁纸宿主

状态：完成（隔离宿主验收）。负责人：Codex 主代理。阶段：实现及隔离验收（用户于 2026-10-11 明确要求完成 T07）。

## 目标

复用可信KOS渲染组件构建无Shell依赖宿主。

## 依赖与开始条件

T03,T06。依赖交付物须可复查；失败或未测不能冒充满足。

## 范围

图片优先，可信主题参数化。

## 具体步骤

1. 梳理组件依赖。
2. 实现crop一致方案。
3. 去除天气/window服务依赖。
4. 明确资源ready与帧事件。
5. 验证独立宿主与离线消费端的静态构图一致；生产三阶段留 T14。

## 交付物

WallpaperHost边界、资源/帧事件定义。记录提交、组件版本和证据相对路径。

## 验收

A03-H 及本卡宿主范围的 A11，不依赖用户 platform socket；完整 A03 留 T14。按 [验收矩阵](../acceptance.md) 与 [证据模板](../evidence/TEMPLATE.md)逐项填写。未测保留未测；证据缺失不得关闭任务。

## 失败回退

静态默认背景。记录触发条件、恢复命令/操作、耗时与最终状态；失败场景必须可重复。

## 非目标

搬运整个桌面Shell。不扩大认证权限、不顺带重构无关模块。

## 约束与评审

遵守 [硬约束](../constraints.md) 与 [AGENTS.md](../AGENTS.md)。存在证据冲突时暂停依赖动作，先澄清事实；普通原型不授权系统服务切换。

## 执行细化

从shared ThemeWallpaperScene和现有图片宿主提取必需输入清单，给时钟、节能、鼠标和资源独立默认值，不导入桌面服务单例。图片宿主验证image decode ready、window mapped、frame提交的不同事件。使用相同资源hash，在独立宿主与离线消费端测试夹具重绘（不要求尚未实现的生产 Cover/桌面），导出裁切坐标和对照截图；检查1.5scale的取整不会移动主体。可信主题缺依赖时静态回退而不挂起整个登录，显示器拔除后销毁对应窗口和事件订阅。

## 完成后的独立子代理审查

每次完成本卡工作，先标记待独立审查，必须调用未参与本卡编写或实现的独立子代理审查当前产物、相关约束和验收证据。执行者修复后交独立代理复审；P0/P1/P2关闭后才能标记完成，P3须记录处置并经审查确认。保存被审版本、代理ID、问题及复审结论。不得用作者自查替代。详见 [独立审查规则](../REVIEW_POLICY.md)，填写 [证据模板](../evidence/TEMPLATE.md)。
