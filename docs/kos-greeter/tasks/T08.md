# T08 登录视觉与退场

状态：阻断（实现与隔离验证已交付；完整 A15 缺同配置实机基准，独立复审通过）。负责人：Codex。阶段：用户于2026-10-11明确授权实施。

## 目标

Tahoe布局及认证成功到纯背景动画。

## 依赖与开始条件

T04 的 A15-R 研究交付、T05、T07。T04 明确记录参考缺口并经独立审查后允许开展概念原型；缺口未补齐时本卡不能宣称完整 A15 或 1:1 通过。其他依赖交付物须可复查，失败或未测不能冒充满足。

## 范围

单用户/多用户/失败/等待/退出。

## 具体步骤

1. 按测量布局。
2. 实现材质回退。
3. 清密码禁输入。
4. 退场180–280ms起点可调。
5. 最后帧提交后launch。
6. 错误保持登录。

状态分镜、参数表、动画录像。记录提交、组件版本和证据相对路径。

## 非目标

## 约束与评审

遵守 [硬约束](../constraints.md) 与 [AGENTS.md](../AGENTS.md)。存在证据冲突时暂停依赖动作，先澄清事实；普通原型不授权系统服务切换。

## 执行细化

视觉入口是独立Greeter状态根组件。把布局常量与视觉材质分开：日期位置、时钟bbox、用户区锚点、头像直径、密码框、状态栏分别可测。使用T04有效基准导出归一化位置和对应物理像素；无基准字段标成建议。

ReadyToLaunch时先清secret、禁输入，触发ExitStarted；建议先让表单/头像淡出，时钟并行或略后，暗罩逐渐恢复到桌面亮度。末帧时检查UI opacity=0、wallpaper crop/scale稳定，不以整屏黑色结束。记录ExitComplete和FrameSubmitted，再调用launch；frameSwapped只能作为提交证据。

减少动态效果设置下应立即或短淡出完成同一状态机。认证失败不得进入Exiting；launch拒绝/连接异常有可见诊断与重建会话路径。用录像核查没有提前launch、残留表单或结束后再播放top切换。
