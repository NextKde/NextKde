# T09 会话wrapper与交接描述

状态：完成（实现/隔离验证及独立复审通过，2026-10-12）。负责人：Codex。阶段：用户于2026-10-12授权完成本卡，已实现并运行隔离验证。

## 目标

安全传递有限展示状态并隔离会话。

## 依赖与开始条件

T02,T03,T06。依赖交付物须可复查；失败或未测不能冒充满足。

## 范围

验证描述、原子runtime文件、清理。

## 具体步骤

1. 限制schema和字段。
2. 拒绝任意路径与命令。
3. 按session命名。
4. 0600写入。
5. 过期/并发/非法输入。
6. 不全局import令牌。

## 交付物

契约实现方案、校验与清理证据。记录提交、组件版本和证据相对路径。

## 验收

A11/A13，跨会话不串数据。按 [验收矩阵](../acceptance.md) 与 [证据模板](../evidence/TEMPLATE.md)逐项填写。未测保留未测；证据缺失不得关闭任务。

## 非目标

认证令牌或全局环境同步。不扩大认证权限、不顺带重构无关模块。

## 约束与评审

遵守 [硬约束](../constraints.md) 与 [AGENTS.md](../AGENTS.md)。存在证据冲突时暂停依赖动作，先澄清事实；普通原型不授权系统服务切换。

## 执行细化

入口是已安装的用户会话wrapper；只接受展示描述引用/有限字段，不拼接命令。验证schema、session标识、过期时间、UID绑定、允许资源路径、hash、输出数量与数值范围。示例中的EXAMPLE路径不得投入运行。

使用真实XDG_RUNTIME_DIR创建本会话专用子目录，权限0700，描述文件0600；临时文件写完后原子rename。用两个同 UID 会话描述的文件级测试验证路径与清理互不覆盖；该测试不代表两个完整桌面可以同时运行。当前 kos-shell.service 与 qs --no-duplicate 属于共享用户实例，完整同 UID 并发桌面尚不支持，须由 T01/T14 确认限制并拒绝不支持的启动组合；若需支持，另立架构任务后验证。退出按拥有者清理，不能glob删除其他会话文件。

非法JSON、未知版本、路径穿越、错误hash、超大字段、旧会话复用和文件替换分别测试。无效描述忽略并使用默认背景，不阻塞认证后进入可用桌面。保存拒绝原因而不输出完整秘密环境；禁止全局systemd/dbus import展示令牌。
