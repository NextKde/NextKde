# T04 Tahoe视觉基准采集

状态：完成（A15-R 研究交付）。负责人：Codex。阶段：研究/方案确认；实现须另有明确授权。

## 目标

补齐同版本单用户/多用户/密码/失败/成功参考。

## 依赖与开始条件

T01。依赖交付物须可复查；失败或未测不能冒充满足。

## 范围

仅合法引用与测量，不宣称已有完整基准。

## 具体步骤

1. 区分锁屏/快速用户切换/冷启动。
2. 记录分辨率字体配置。
3. 采集关键帧。
4. 测量位置和轨迹。
5. 标记缺口。

## 交付物

来源清单、标注图、测量表、版权说明。记录提交、组件版本和证据相对路径。

## 验收

A15-R，每个目标状态有来源或明确缺口；缺口须记录补采计划及原型影响。研究交付通过不代表完整 A15 通过，完整 A15 留到 T08/T14。按 [验收矩阵](../acceptance.md) 与 [证据模板](../evidence/TEMPLATE.md)逐项填写。产品状态未测保留未测；研究交付所需的来源登记、缺口清单和独立审查记录缺失时不得关闭本卡。

## 失败回退

保留概念示意标签，延后1:1验收。记录触发条件、恢复命令/操作、耗时与最终状态；失败场景必须可重复。

## 非目标

把宣传图当全部状态。不扩大认证权限、不顺带重构无关模块。

## 约束与评审

遵守 [硬约束](../constraints.md) 与 [AGENTS.md](../AGENTS.md)。存在证据冲突时暂停依赖动作，先澄清事实；普通原型不授权系统服务切换。

## 执行细化

建立参考登记表：来源URL、采集日期、macOS构建、锁屏或冷启动/快速切换、输出尺寸、字体配置、用户数量和版权。官方宣传图先标设备外框，测量前不能用整图当屏幕像素；512 Pixels文件名与页面名称一起保留。对缺少的密码展开、等待、失败和成功退场逐项列缺口，只有实际取得录像才抽关键帧。测量日期/时钟/用户bbox和归一化锚点，动画记录采样率、轨迹和误差；无法取得的值保持建议。

## 完成后的独立子代理审查

每次完成本卡工作，先标记待独立审查，必须调用未参与本卡编写或实现的独立子代理审查当前产物、相关约束和验收证据。执行者修复后交独立代理复审；P0/P1/P2关闭后才能标记完成，P3须记录处置并经审查确认。保存被审版本、代理ID、问题及复审结论。不得用作者自查替代。详见 [独立审查规则](../REVIEW_POLICY.md)，填写 [证据模板](../evidence/TEMPLATE.md)。
