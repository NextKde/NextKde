210: `./tools/kosctl uninstall` 检测到残留会提示。登录界面黑屏或无法输入密码时，按
211: Ctrl+Alt+F2（或 F3/F4…）切到 TTY 登录，删掉主题选择文件并重启显示管理器即可

16: PartOf=graphical-session.target

18: [Service]
19: Type=simple
20: # Detached processes keep the launching cgroup even after fork+setsid. Use
21: # process mode so restarting the Shell signals only the main qs process and
22: # leaves applications launched from the Dock alive. mixed is insufficient: it
23: # sends SIGTERM only to qs first, but then SIGKILLs every remaining cgroup
24: # process as soon as qs exits.
25: KillMode=process
26: # The installed shell must be stable: `sync`/`install` overwrite the config
27: # directory it watches. Disable the file watcher so a copy in progress can
28: # never trigger a hot-reload of half-written QML (which crashes quickshell).
29: # QML edits take effect via `kosctl start`, or via `kosctl dev` (which runs
30: # from the source tree with its own watcher and sockets).
