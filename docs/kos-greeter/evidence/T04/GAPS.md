# 状态覆盖、补采计划及原型影响

本次无可核验 Tahoe 认证录像；不抽取伪关键帧。A/B 是静态样本，全部动态参数、时间和曲线仍未知。

| 目标状态/流程 | 当前来源或明确缺口 | 补采内容 | 对 T08 原型与 A15 的影响 |
| --- | --- | --- | --- |
| 单用户锁屏待输入 | A：单个可见用户、Touch ID/输入密码提示；非密码展开 | 同构建真实锁屏，记录用户配置、字体、模式，保存无秘密输入的静态帧 | 仅借鉴上方时钟、下方身份区；原生像素/字体未校准 |
| 多用户选择 | B：两行用户；快速切换/锁屏相关参考，入口未经验证 | 在同一台机器同构建复现快速切换与注销返回，分别采集 | 纵向头像/右侧名字有静态参考；不认定冷启动布局一致 |
| 冷启动单用户/多用户 | 缺口，包括 FileVault 前置解锁与系统登录区别 | 分别记录 FileVault 开/关、冷启动到系统登录的流程标签；不可混合解锁界面 | 冷启动布局不具备 1:1 验收条件 |
| 密码展开/焦点 | 缺口；A 的提示文字不是密码框证据 | 测试账户空密码框、焦点、Caps Lock、切用户后框位置；不记录秘密 | 密码尺寸、展开位移和时间保留概念建议 |
| 认证等待 | 缺口 | 受控测试账户记录提交后等待反馈，仅截背景/UI无秘密区域，保留原始帧时戳 | 等待图标、旋转/淡入时长未知 |
| 失败与重试/取消 | 缺口 | 测试账户受控失败与重试，采集错误反馈；避免锁定真实账户；记录恢复操作 | shake 轨迹、文案位置、错误清除时间未知 |
| 成功退场至纯背景 | 缺口 | 使用测试桌面无个人窗口，记录 UI 最后可见帧、纯背景首帧与触发时间 | 180–280ms 等既有数值继续是建议，不能称 Tahoe 实测 |
| 桌面入场/菜单与其他用户 | 缺口 | 同版本录制 bar/Dock 出现、菜单展开和其他用户入口；只保留无敏感内容的区域 | KOS 门控是自主设计；不借 B 推断入口或过渡 |

补采负责人：后续 T08 执行者；在 T08 同状态视觉校准前准备获授权的 Tahoe 测试设备或权利人授权录像。没有设备时可推进带“概念示意”标签的原型，但完整 A15 必须保持未测，T14 汇总不能跳过缺口。

采集协议：记录 `sw_vers` 产品版本/构建、设备、分辨率、有效缩放、刷新率、语言、时钟定制、字体配置（不能获取就写未知）、用户配置和可访问性。每组流程使用同构建同配置，状态分别编号；使用测试身份，不采集密码/个人窗口。静态无损图用于 bbox；动态视频保留真实 PTS/时基、帧率、曝光、录制方式、丢帧与时间误差。建议 ≥60fps，优先120fps；这是采集建议，并非已有录像参数。仅测 UI 动画，不据屏幕录像证明物理 scanout 或 KOS 跨 KWin 黑帧。

录像到手后按状态转折选关键帧（输入前、等待、失败峰值/恢复、成功UI终帧/纯背景），记录文件 hash、PTS、bbox；位移相对同一屏幕原点，时间误差至少含一帧采样间隔。不能从两个静态图插值制造轨迹。补采必须在不留下凭据的条件下执行；不能满足即停止采集并标记缺口。

回退复现：没有录像或来源 HTTP403 → 在研究报告保留缺口和现有本地图摘要 → 不更新实测动画参数 → 原型保留概念标记。恢复操作是使用已保存研究样本/停止该来源采集，不改系统；恢复耗时不适用。最终状态：现有登录会话和服务未改动。设备/素材取得是后续补采条件，不是本次 A15-R 的遗漏交付。
