## 静态测量方法与边界

坐标是原始文件像素，原点左上，bbox=[x0,y0,x1,y1)；锚点是 bbox 中心。A 先排除设备外框，使用近似可见屏幕矩形 x=154,y=83,w=672,h=437；圆角/顶部缺口不做透视矫正，屏幕边界误差约 ±2px。A UI 边缘手工误差估计 ±3px，B ±6px；这些是保守估计，不是统计置信区间。观察时 B 的预览可能缩小，已换算回 2880×1800 源坐标，不能称逐像素分割结果。文字 bbox 只含可见字形，不是 QML 文本框、基线、字体度量或字号。

归一化中心 nx=(cx-screen.x)/screen.w，ny=(cy-screen.y)/screen.h。A 同时保留整文件坐标以复查；严禁把 980×653 整图当原生屏幕。B 使用全图，不从图片尺寸推断物理分辨率或 Retina scale。详尽数据以 CSV 为准。
