# 验收矩阵与阻断条件

状态统一为：未测 / 通过 / 失败 / 阻断；当前全部未测。每次执行填写 [证据模板](evidence/TEMPLATE.md)。截图只验证静态视觉，不验证动画、认证正确性或零黑帧。

| ID | 场景/要求 | 通过条件 | 必需证据 | 失败恢复 |
|---|---|---|---|---|
| A01 | 最小登录生命周期 | 正确认证后退出登录会话并进入指定 Plasma；无双 KWin 残留 | 版本、进程树、脱敏日志、录像 | 原显示管理器/TTY恢复 |
| A02 | 认证失败 | 不启动桌面，清空敏感数据，允许再次输入 | 错误/取消/重复认证录像 | 重建认证会话 |
| A03 | KOS 静态壁纸 | 同资源 hash、crop、fit、输出和缩放；不使用 Plasma 占位 | manifest、三阶段截图 | 内置默认背景 |
| A04 | 240 Hz / 1.5 | 当前机器两阶段目标模式有效，记录实际 Hz 与坐标 | kscreen 输出与录像 | EDID 安全模式 |
| A05 | 多屏/合盖/拔线 | 没有离屏密码框、死窗口或无限 modeset；主屏明确 | 每场景录像、输出事件 | 保底活动屏显示 |
| A06 | 多用户身份 | UserName用于认证，RealName显示；Other user可用 | 脱敏字段与录像 | 登录名/默认头像 |
| A07 | 不可读/损坏头像 | 无崩溃、无 home 权限放宽 | 错误注入日志 | 默认头像 |
| A08 | 退场 | 成功后先退 UI 留纯背景再 launch；失败不退到桌面 | 状态时间线与录像 | 保持或回到登录 |
| A09 | Cover 启动 | 不依赖 platform/data；尽早映射且记录帧证据 | 服务依赖、进程和帧时间线 | 受控退出，不永远遮盖 |
| A10 | 桌面揭幕 | 正式背景匹配，bar/Dock统一门控；不播放一次 top切换 | 冷/热启动录像 | 超时撤罩/诊断提示 |
| A11 | 资源丢失/版本不兼容 | 固定默认背景；安全拒绝未知字段/不可信路径 | 故障注入与校验日志 | 默认契约 |
| A12 | 动态/空间背景 | 明示静态回退或状态恢复；不登录推理、不执行未知QML | 帧比较、资源清单 | 静态背景 |
| A13 | 隐私 | 日志/描述/截图无密码，无全局令牌导入 | 人工审查、数据样例 | 清理产物与修复 |
| A14 | 崩溃/启动超时 | Greeter/Cover/Shell每种故障都可恢复，无无限循环 | 故障注入和恢复记录 | TTY/原管理器 |
| A15 | Tahoe视觉 | 基准同版本/配置/状态；已测区域误差和未测区域清楚 | 叠图/标尺/来源/版权 | 标记概念未达标 |
| A16 | 黑帧量化 | 统计空白帧数和时长，不把未测写零 | 高频外部录像、采样率 | 降级声明，另立性能卡 |

## 测试组合

基础组合：冷启动、注销返回、认证失败、取消、切换用户、用户 home 不可读、图片缺失、schema 过期、Greeter 崩溃、Cover 崩溃、Shell 延迟/失败。显示组合：本机内屏 240 Hz/1.5、推荐模式、外屏接入/拔除、合盖、多屏不同缩放。动态组合：时间主题、粒子静态回退、空间预生成素材。

## 分阶段门槛

G0 文档与来源可复查；G1 隔离环境最小认证/恢复通过；G2 身份/资源/输出合同通过；G3 静态背景与动画完整闭环通过；G4 故障注入通过；G5 才评审实机系统集成。跨实例零黑帧是单独指标，不作为首版已承诺能力。

严重阻断：密码泄漏、任意用户代码登录前执行、无法恢复登录、Cover永久遮盖、启动循环、未授权切换系统服务。视觉不完整也必须标注，不能用成功单场景掩盖。

## 每次任务的独立审查验收

A17 独立子代理审查是每次任务的完成门槛：调用未参与该任务编写或实现的审查代理，审查最终产物与证据；修复后复审。保存代理 ID、被审版本/摘要、问题处置与结论，P0/P1/P2 未关闭不得完成。依赖作者自查、未审修复或过期版本审查记录均不通过。见 [独立审查规则](REVIEW_POLICY.md)。

## 分阶段验收边界

早期任务按下列子项关闭，完整主项仍保留待测；最终集成 T14 必须汇总主项，不能以子项代替。

| A03-P | T03 发布图像哈希、权限、版本、裁剪参数及消费契约；尚未实现的消费端明确待测 | A03 三阶段画面由 T07/T10/T11/T14 验证 |

A18 壁纸公开发布生命周期：每账户明确同步选择及认证前可见范围；未选择、撤销、账户删除时不能继续显示私有资源。证据覆盖 manifest 撤销、缓存/快照失效、旧版本垃圾回收及中断恢复。T03 验证发布侧，T14 验证所有消费端。

A19 独立 app 与安装：具有独立源码/资源、运行与构建/打包入口、明确依赖、专属安装命令及卸载升级恢复说明。干净环境可独立安装，不要求天气等无关 app；重复安装/缺依赖/升级失败有明确结果。安装不自动切换当前显示管理器，普通 app 合集不顺带启用 Greeter。T01 完成结构设计，T14 汇总真实安装与恢复证据；当前全部实现测试待测。
