# 视觉与动画规格草案

这是设计约束草案，概念值与实测值严格分开。现阶段Apple官方锁屏宣传图与512 Pixels多用户参考不足以形成所有状态的1:1测量。

## 基准坐标与资产

设计坐标按每输出逻辑尺寸计算，物理像素以实际scale换算；本机2560×1600/1.5不是可以直接套用的Tahoe像素基准。日期、时钟、用户区、状态图标分别使用独立锚点，避免中央表单把留白填满。填满屏幕沿用KOS crop；多屏各自计算，不把一张横向截图拉伸。

现有分镜只展示布局关系，头像、字体、玻璃均占位。最终字形须记录字体文件版本、字体许可、字号、字重、字宽与数字间距。不得以看起来相近宣称系统字体相同；禁止随包分发未经许可的Apple字体。

## 状态视觉

| 状态 | 必须表达 | 校准来源 | 当前状态 |
|---|---|---|---|
| 单用户待输入 | 大时钟、下方头像/名字、小密码区域 | 同版本实机单用户图 | 仅官方锁屏构图参考 |
| 多用户选择 | 纵向头像及右侧名字，其他用户入口 | 512 Pixels参考 | 静态布局可研究 |
| 密码/认证等待 | 清楚输入焦点、等待反馈 | 待收集实机录像 | 概念建议 |
| 失败 | 留在登录、清secret、错误反馈 | 待收集 | 不承诺原版轨迹 |
| 成功退场 | UI消失至纯壁纸 | 待收集 | 建议时间轴 |
| 桌面入场 | 同背景接点、bar/Dock统一揭幕 | KOS自己的产品设计 | 非macOS测量 |

## 建议动画时间轴（待实测调整）

t=0：ReadyToLaunch，清密码并禁输入；认证等待动效停止。t=0–200ms：表单/头像淡出；时钟可延后约30–60ms起步；整体建议完成时间180–280ms。背景只恢复到约定的桌面亮度，不默认缩放移动。t=ExitComplete：UI完全不可见，等待背景终帧提交，再launch。launched后结束Greeter，禁止等待新桌面信号。

新KWin接管后：Cover尽早画同一背景；后台必要组件就绪后建议200–300ms撤罩/显露。以上都不是Tahoe测量值，T04实机参考与可访问性要求可替换。减少动画时短淡出或直接完成状态，不能跳过凭据清理和生命周期顺序。

## 材质与性能

时钟优先准确字形与透明关系，再加背景采样、边缘高光和细微折射。透明文字不能仅靠深色整屏遮罩增强。shader失败/软件渲染使用普通浅色文字与轻阴影，仍保持认证功能。记录GPU成本，避免240Hz下材质造成帧延迟。

## 验收方法

基准截图必须同状态、分辨率、字体配置与壁纸。测量bbox、归一化锚点、头像/密码框尺寸、亮度及对齐，输出叠图和差异说明。动画用录像测轨迹与时间；严格黑帧用外部视频另测。像素误差阈值由T04基准报告提出并评审，在缺少素材时不虚构固定误差通过标准。

## 禁止事项

不把概念HTML当实机预览；不把静态相似当动态连续；不截带密码的整屏；不使用Plasma占位背景；不在登录接点再次播放从上滑入。
