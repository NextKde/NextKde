# 硬约束

以下约束适用于未来实施评审；本包只创建文档，不包含系统集成授权。

## 安全与权限

C01 认证交给 greetd/PAM；禁止保存、日志输出、截图或环境变量传递密码。
C02 登录前不得执行用户提供的任意 QML/脚本；第三方主题必须经过信任审查，否则静态回退。
C03 登录前不依赖 home 可读性，不放宽 home 或平台 socket 权限；展示资源由显式发布流程提供副本。
C04 交接数据为有限 schema；严格限制路径、尺寸、长度、类型、版本与过期时间。禁止 shell 拼接或执行描述中的命令。
C05 用户运行时描述 0600，按 session 隔离；不能全局 import systemd/dbus 令牌。

## 生命周期与恢复

C06 Greeter 动画在 launch 前完成；不得等待用户桌面首帧后才退出。
C07 launched 不视作桌面就绪；资源 ready 不视作 scanout。
C08 Cover 不得依赖完整 kos-platform/data；KWin 尚未接管阶段不能谎称已遮盖。
C09 启动、Cover、资源、认证均须超时/失败路径；不得留下永久遮盖层、僵尸登录 KWin或无限重启。
C10 系统集成前验证可用 TTY、可恢复的原显示管理器和配置备份；具体切换需单独明确授权。

## 视觉与输出

C11 壁纸权威来自 KOS，Plasma 占位不作为同步源。登录终帧、Cover、桌面使用一致资源版本、crop、scale、mode。
C12 登录入场抑制一次日常 top 壁纸切换；不改变日常更换壁纸偏好。
C13 选择用户不默认 modeset；输出使用机器默认和安全回退。
C14 不截含密码或用户窗口的整屏，动态回退仅捕获背景层。
C15 动态 phase 不代表完整 GPU 状态，空间素材不在登录时推理。
C16 1:1 声明必须有同状态实机基准；概念示意不得冒充 Tahoe 测量。字体和素材授权独立检查。
C17 “零黑帧”只有真实跨会话录像/presentation 证据可支持，不能由动画截图推导。

## 变更范围

C18 首先使用隔离环境和最小原型。不得为视觉任务顺带替换锁屏认证、调整系统 PAM、安装任意主题或重构整个 Shell。
C19 每项验收提交明确版本、机器、输出、证据及失败回退。未测项目标记未测，禁止补写结果。

## 独立审查完成门槛

C20 每次任务交付必须调用未参与编写或实现的独立子代理审查。没有独立审查不得报告完成；修复后必须复审。P0/P1/P2 关闭、P3 处置经审查确认后，才可关闭任务。保存被审版本、审查代理、问题处理与复审结论。详见 [独立审查规则](REVIEW_POLICY.md)。

C21 登录背景同步须取得每账户明确选择，并说明认证前可见范围；桌面选图不自动授权发布。撤销、账户删除和版本替换须使相关 manifest、缓存与快照失效并清理旧资源；未授权或已撤销资源使用内置背景。

C22 同 UID 文件隔离不等于完整桌面并发支持；当前共享 kos-shell.service/qs --no-duplicate 限制须在 T01/T14 明确验证，不能承诺未经实现的并发会话能力。

C23 Greeter 必须作为本项目独立 app 组织，提供专属安装入口及卸载/恢复说明；不得要求安装无关应用。资源安装与持久启用分离，普通 app 合集安装不得顺带切换显示管理器。见 [App 安装方案](app-packaging.md)。
