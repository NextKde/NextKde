# 窗口动画

[English](WindowAnimations.md)

在 KOS 设置 → 窗口与动画 → 隐藏与恢复中，点击展开下拉菜单，选择 **无、缩放、神灯**。
选项在弹出菜单中显示，不平铺为桌面控件。关闭窗口动画有独立下拉菜单。

神灯使用 KWin 官方开源 **Magic Lamp**（`magiclamp`）。源码位于
[KWin 仓库](https://invent.kde.org/plasma/kwin/-/tree/master/src/plugins/magiclamp)，
不是需要另外下载的 KOS 插件。标准 Plasma/KWin 软件包通常包含它，但 KWin 默认不启用；
在 KOS 中选择“神灯”后，项目负责启用并发布 Dock 图标落点，最小化和恢复共用这个位置。

原生效果缺失、不支持或加载失败时，KOS 自动采用自己的缩放动画，并显示回退原因。
“神灯”偏好仍会保留，之后启动时重新检测，支持恢复后可以自动切回原生效果。
旧“水滴”配置自动迁移；“无”会保留或恢复用户原先的 KDE 最小化效果选择。

通常不需要手动安装或配置。出现回退时：

1. 打开 KDE 系统设置 → 桌面特效，搜索“神灯”或“最小化”。完整中文名称为
   “最小化过渡动画 (神灯)”。若需修改时长，可使用该效果的配置按钮。
2. 若找不到，通过发行版软件管理器修复或更新匹配的 Plasma/KWin 软件包。
   Fedora 对应 `kwin`，Arch 对应 `kwin`，Debian/Ubuntu 对应 `kwin-wayland`，
   NixOS 使用所选的 `kdePackages.kwin`；具体拆包随发行版和版本变化。
   KWin 和 Plasma 应来自同一受支持的发行版版本。
3. 软件包或图形环境变化后，注销重新登录，再选择神灯。原生支持恢复之前，缩放是自动回退。

标准安装不需要从源码编译另一份神灯，额外编译可能与当前合成器 ABI 不匹配。
KOS 不关闭 KWin 权限检查，也不从设置菜单自动安装系统软件包。

拉取 commit 只更新源码。需要通过项目正常安装流程重建并安装修改后的设置和平台组件，
再重启用户服务。更新后的 KWin 插件二进制在注销重新登录后生效，不热替换。
见[入门指南](GettingStarted.zh-CN.md)。
