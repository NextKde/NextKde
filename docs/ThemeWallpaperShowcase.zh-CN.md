# 动态主题壁纸：主景重设计

本分支重做森林、水下、星空和天气四个主题的主画面。黑洞主题不在本次改动范围。

## 设计内容

| 主题 | 主景 | 动态细节 |
| --- | --- | --- |
| 森林 | 冷蓝月光、四层针叶林、林间空地与湖面倒影 | 树梢轻摆、分层薄雾、倒影涟漪、偏暖色萤火 |
| 水下 | 非对称深蓝峡谷、明亮水面入口、岩壁与沙床 | 折射光束、流动焦散、鱼群、气泡与点击水波 |
| 星空 | 斜向星云、偏右上亮核、冷蓝气体与暖色尘带 | 气体缓慢变化、稀疏闪烁星点、鼠标扰动 |
| 天气 | 两侧云墙围出的天光通道、连续云海与远景空气透视 | 云体漂移、银边与天光，沿用昼夜和雨雪输入 |

森林和水下的主景改由 shader 绘制，不再采样原来的静态场景底图。已有鱼群、萤火和组件交互保留。星空与天气沿用缓存画布，按画面变化更新；背景更新上限分别为 24/12 帧，省电模式为 6 帧，实际帧率仍受宿主时钟与设备性能限制。

## 待人工查看

安装并重新登录后，在“设置 → 壁纸”分别预览四个主题：

1. 森林：检查月亮、树林、湖面和萤火的层次，以及窄屏时月光焦点是否仍在画面内。
2. 水下：检查岩壁与水体的分离、鱼群和气泡的前后遮挡，以及光束是否过亮。
3. 星空：检查亮核、暗尘带与桌面文字的对比度，留意星点是否闪烁过强。
4. 天气：检查白天、夜晚和雨雪条件下云层的亮度及轮廓，留意云体采样条纹。
5. 移动鼠标、点击桌面、放置组件，再切换省电模式，观察交互和动画是否自然。

完成实际截图后，再将真实画面补入本页并更新主题缩略图；不以概念图或旧截图代替运行结果。
