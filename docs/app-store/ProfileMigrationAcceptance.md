# 人工验收：独立新身份与显式旧版清理

**安装边界：原生版与 Flatpak 版允许共存。** Settings 的“安装／打开／卸载”只看当前
Flatpak 库存；原生程序、桌面入口、源码安装记录均不得阻止查询、计划或安装。
旧原生清理是独立可选操作，绝不是安装 Flatpak 的前置条件。
卸载入口：点击应用图标或名称展开详情 →“卸载”→确认；仅删除选中的用户级 Flatpak，
保留个人资料、配置和原生应用。系统级或多份 Flatpak 须由对应管理器明确处理。

2026-11-05：新旧 Calendar／Calculator／Weather 是不同应用，允许 breaking change。
不再要求旧资料回读、原生同路径升级或 Calendar 重装接续旧资料；以前的结果仅为历史证据。
本轮已完成源码修改、专用 VM 生产编译，以及下述明确授权的清理器隔离假资料验证；不把编译或夹具结果记作人工运行验收。
以下矩阵仍待人工在可丢弃的独立测试用户环境中执行，不使用真实资料。
自动化例外仅限本次清理器临时夹具，不扩展到应用生命周期、UI、截图断言、smoke 或 headless 启动。
