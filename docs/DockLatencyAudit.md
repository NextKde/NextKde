# Dock 交互时序静态审查

审查日期：2026-10-13。以下清单保留优化前的审查基线；文末记录本轮实施结果。范围：Dock、名称/窗口预览、Stack、音乐、温度详情、融入 Dock 的托盘、公共弹窗动画，以及相关状态服务。

未运行 Shell、测试或性能测量。下表是源码设计时序；动画时长不是启动前等待，Qt 帧调度、Wayland 映射、IPC 和缩略图捕获还有不定耗时。没有发现所有路径共用的额外 hover 启动等待；名称、预览和信息卡分别设置停留时间。

## 直接交互

| 项目 | 当前时序 | 审查结论 |
| --- | --- | --- |
| 鼠标横向跟随 | 下一次共享 FrameAnimation 更新，无位置缓动 | 保留。每帧一次完整快照，存在输入到下一帧的调度间隔，不能称为零延迟。 |
| 放大进入/退出 | 指数响应时间常数 26ms，约 60ms 到 90%；epsilon=0.0001 | 不是先等 26ms。逐帧立即推进；完全停止需要尾段收敛。 |
| 单帧响应上限 | delta capped at 1/30s | 非正常低帧率/卡顿时不会按全部实际时间追上，可能延长进入退出。需在虚拟机观察后再决定是否调整。 |
| 原生 hover 丢失宽限 | 80ms | 保留防瞬时 leave/enter。原生丢失且最后位置仍在 Dock 时也可能让真实离开滞后 80ms；不是普通横移的延迟。 |
| App 名称 | 停留 180ms 后显示 | 用户要求的等待；不同 owner 重启，同 owner 不重启。无额外名称入场动画。 |
| 名称定位 | Qt.callLater(anchor.updateAnchor) | 无固定 ms 等待，推迟到事件循环后续，以合并更新并让 transform 生效；原生弹窗重新定位仍可能有显示端延迟。 |
| 非玻璃 hover 背景 | 70ms OutCubic | 当前已缩短；绘制响应，不影响图标位置。 |
| 玻璃 hover/激活高亮 | 70ms OutCubic | hover、selection、presence 共享时长；也影响窗口激活的外观过渡。 |
| 玻璃按下反馈 | 45ms OutCubic | 当前已缩短。 |
| 非玻璃按下反馈 | pressFadeIn/pressFadeOut 各 150ms | **遗漏：未跟随 45ms 常量。** 两个 NumberAnimation 分别驱动同一 opacity，按下/释放处理未显式停止相反动画，快点或连点有相互覆盖风险。应统一响应常量和动画所有权。 |
| 独立宿主单图标反馈 | 两个 SpringAnimation：spring=8、damping=.4、mass=.6 | 只用于没有共享距离放大的宿主；主 Dock 共享路径不依赖它们。没有固定“等待 N ms”。 |
| 紧急/外部动作反馈 | 并行放大/上移/发光 115ms，恢复 210ms | 不是 hover 等待；会与基础 hover 视觉变换组合。应单独验证交互，不建议当作 hover 曲线调节。 |
| 长按编辑 | MouseArea 平台默认长按阈值 | 没有代码内统一 ms 值；不能把平台阈值当成本项目固定时长。拖动识别还依赖平台距离阈值。 |
| 离开编辑模式 | 400ms | 防误退出，适用于编辑模式。 |
| 拖动邻居让位/源落位 | 180ms | 源正在拖动时禁用该位置 Behavior，直接跟手；释放和邻居才过渡。 |
| 拖动层 scale/opacity | 各 120ms | 只在 drag/settling 状态变化，不在普通 hover 中持续追赶。 |
| 拖动释放结算 | Timer 16ms | 等 Row/Repeater 新几何。固定 16ms 不是可靠的“下一帧”语义，高刷新率和卡顿时不一致；宜改为明确布局结算机制，而非直接删掉保护。 |
| 常规 Dock 宽高变化 | Windows12 120 / Material 100 / 其他 135ms | hover 内禁用尺寸 Behavior，普通模型增减才动画。 |
| Dock 整体出现/消失 | Windows12 180 / Material 220 / 其他 200ms | 内容整体透明度，不是普通图标 hover。 |

关键代码：`DockAnimation.qml`、`DockContainer.qml`、`DockIcon.qml`、`DockAppNameTooltip.qml`、`SelectionHighlight.qml`。

## 窗口预览与信息卡

| 项目 | 当前时序 | 审查结论 |
| --- | --- | --- |
| App 窗口预览打开 | 停留 300ms | 有意过滤快速扫过。已打开预览时进入同图标仍会先等此计时器才走快速恢复路径，切换应用也重新等待；可优先优化“已有预览时切换”，保留首次停留保护。 |
| 预览动画启动 | Timer 16ms | visible=true、revealProgress=0 后等待启动。名义上首显至少在 300+16ms 后，不含映射/捕获。固定 16ms 不保证原生窗口已就绪。 |
| 预览入场 | 120ms | 从零 revealProgress 渐显；名义完全展开约 436ms，不能把这个值说成首次可见延迟。 |
| 预览恢复 | 30ms | 只在 popup 已 visible 且 closing 时使用。外层 300ms 停留计时仍可能先挡住恢复。 |
| 预览关闭等待 | 130ms | 鼠标从图标跨到预览的保护，应保留。 |
| 预览退场 | 110ms | 关闭等待后执行；正常离开至完全隐藏名义约 240ms，若触发原生退出宽限可再加 80ms。鼠标进入预览时取消关闭。 |
| 预览卡片视觉反馈 | 颜色、边框、关闭按钮 opacity 各 100ms | 绘制过渡，不延迟点击动作。 |
| Stack 信息详情首次打开 | 停留 420ms | 明显等待，之后还叠加公共入场 150ms；可统一到更短的首次停留策略。已打开时页面切换存在立即更新路径，不能把每次切页都算 420ms。 |
| 音乐详情首次打开 | 停留 420ms | 同上；进入计时器没有统一的“已打开/同目标不重启”状态守卫。 |
| 温度 dashboard 首次打开 | 停留 420ms | 同上；不应与普通文字 tooltip 的等待完全同等处理。 |
| 信息/音乐/温度关闭等待 | 260ms | 跨窗口保护，之后公共退场 140ms，名义完全退出约 400ms。 |
| 公共 AnimatedPopupWindow 入场/退场 | 150 / 140ms，起始 scale=.96 | 没有另一个固定映射前 Timer；动画开始即映射。interactive 在 progress>.01 后启用，不必等 150ms 结束才能点击。 |
| 托盘文字 tooltip | 无停留 Timer，公共动画 150 / 140ms | 与 App 名称策略不一致。它来自 AnimatedPopupWindow，展开后使用默认可交互输入区域；纯文字标签应像 App 名称一样设置空输入 mask。 |
| StatusTooltip | 无自身停留 Timer，公共动画 150 / 140ms | 上游决定 shown；同样没有纯标签专用空输入 mask。应区分标签和可交互 popup。 |
| 托盘菜单后备显示 | 最多等 400ms 才强制显示 | 正常 DBusMenu 数据到达会提前显示，不是所有点击必等 400ms。属于失败/慢客户端保护。 |
| 横/侧 Stack 滚轮冷却 | 180ms | 第一次立即切换，之后窗口内滚轮事件被忽略。连续滚动可能感觉被限速；宜做输入合并而非每次丢弃。 |
| Stack 页面位移/淡入 | 位移 260ms，opacity 220ms | 仅页面切换。用户频繁滚动会重定向过渡，可能进一步放大冷却的慢感。 |
| Stack 自动轮播 | 30000ms | 周期行为，不是交互等待。 |
| 音乐槽及分隔线宽度变化 | 320ms | 对音乐内容变化/展开适用，不是 App hover。宽度动画可引发整体内容重排，需与模型变化一起评估。 |
| 音乐文字跑马灯 | 停留 1200/800 或 900/650ms；滚动至少 900 或 800ms，按文字宽度增加 | 阅读节奏，保留，不影响操作动作。 |
| 音乐音量/播放波形装饰 | 分列起步 index*85ms，高低态 220/260ms | 装饰节奏，保留。 |
| Reveal handle hover | scale 120ms，环境效果 600ms | 视觉反馈，展开 Dock 的等待由自动隐藏控制器单独决定。 |
| 组件编辑器项目 | scale/opacity 120ms | 编辑反馈，不是普通 hover。 |

## 自动隐藏

| 项目 | 当前时序 | 审查结论 |
| --- | --- | --- |
| 状态评估合并 | 80ms，重复 restart | **有无限延期条件：事件持续间隔小于 80ms 时，评估等到最后一次事件后才执行。** 应让输入/弹窗抑制事件及时处理，窗口变化使用有最长等待上限的合并。 |
| 屏幕边缘悬停唤出 | 90ms | 然后执行 180ms 展开，名义全展开约 270ms；点击 handle 走立即唤出路径，不能算所有唤出都等 90ms。 |
| 自动隐藏/展开动画 | 180ms | 反转按剩余距离缩短，但最低 70ms；靠近完成时的小幅反转仍可能显慢。 |
| Smart 冲突隐藏等待 | 200ms | 抗窗口几何抖动。可与 80ms 评估等待叠加，普通名义链路评估→等待→退场为 460ms。 |
| Persistent 离开等待 | 900ms | 保留易重返设计；还可能叠加 80ms 原生退出宽限、80ms 状态评估和 180ms 退场。各条件成立时名义约 1240ms 到完全隐藏。 |
| 切入 Persistent 首次确认 | 700ms | 仅运行中模式切换的首个隐藏等待；直接以 persistent 启动会跳过。 |
| 启动就绪等待上限 | 450ms | 等配置和窗口状态的后备上限，不是无条件启动延迟。 |
| 紧急窗口临时显示 | 2200ms | 提示保持时间；不是进入延迟。 |

## 状态与发布服务

| 项目 | 当前时序 | 审查结论 |
| --- | --- | --- |
| KWin 激活请求 | 24ms restart 合并 | 每次普通 activate 都先等计时；首击可以立即发出，再合并后续重复请求，优先于继续缩短 hover 动画。 |
| 窗口状态重建 | 40ms restart 合并 | focus/minimize/title/appId 等事件都可能推迟展示状态；持续事件可不断延长。应保证合并有上限，避免状态更新迟于动作太多。 |
| toplevel 数量后备轮询 | 500ms | 正常信号之外的兜底，不是每次开窗等待 500ms。 |
| Dock 配置保存 | 500ms 防抖 | UI 属性先更新再保存，不影响即时反馈。保留。 |
| 桌面项身份缓存清理 | 180ms 防抖 | 合并安装项扫描，间接影响名称/图标刷新，不直接驱动 hover。保留并与实时输入隔离。 |
| 最小化目标发布 | 80ms 合并 | 不直接控制 hover；目标更新会有窗口期，操作前已有 prepareLaunch/目标请求链要单独保证最新数据。 |
| 最小化目标几何重发 | 250ms | 定时后备更新；payload 比较抑制相同数据发送。 |
| 最小化目标 heartbeat | 3000ms | 特效重启恢复，不影响通常 hover。 |
| 启动 ticket 确认 | 等平台 IPC 回调，无本地固定延迟 | 保证 ticket 在窗口映射前存在。会串行挡住真正 launch；优先提供即时按下反馈，不应直接去掉协议顺序。 |
| 窗口→图标 renderer 交接 | animation duration - 60ms，默认 Timer 240ms | 动画末段资源切换，不是鼠标 hover 等待。 |
| 图标 renderer reload | 0ms Timer | 下一事件循环合并，不能理解为睡眠。 |
| Launcher presentation / workspace 发布 | 各 0ms Timer | 合并更新，无固定人感等待。 |
| Dock 壁纸材质位置上报 | 67ms 周期 | 约 15Hz 采样；实际读取路径是否造成玻璃背景滞后，需要单独核对渲染消费者，不能据此断言 icon hover 被限成 15Hz。 |
| MPRIS 玩家重建锁 | 120ms | 多次玩家更新合并，影响播放器状态，不是 hover。 |
| MPRIS 启动补查 | 每 600ms，最多 4次 | 无播放器时补查，不是每次打开音乐详情的等待。 |
| MPRIS 元数据 / 歌词位置 | 各 500ms | 服务周期更新；歌曲名称/歌词有采样延迟。 |
| 音乐 popup 进度刷新 | 250ms，仅可见且播放 | 进度条数据频率，非输入节流；拖动 seek 的函数直接写 position。 |
| 通知/状态 badge | opacity 140ms，通知 scale 160ms | 状态装饰。 |
| running indicator | opacity 140ms | 与窗口状态重建延迟可能叠加视觉收敛，但点击/激活不等它。 |
| 背景与 running indicator 状态色 | 150ms | 状态色过渡；与已缩短的高亮时长不完全统一。 |

## 优先顺序

1. 修正非玻璃按下反馈的 150ms 漏项，并停止相反方向动画；检查纯 tooltip 的输入 mask。
2. 激活首击直接发送；状态评估和窗口状态重建合并增加最长等待约束，避免连续事件无限延期。
3. 区分首次预览停留与已经打开后的切换/恢复；不要每次都重等 300ms。
4. 收敛 420ms 信息卡等待和 180ms 滚轮限速；保留跨窗口关闭保护。
5. 用真正的布局/窗口就绪条件替代固定 16ms “等一帧”。

## 本轮实施结果

| 路径 | 修改后的行为 |
| --- | --- |
| 按下反馈 | 两种样式统一 45ms；相反动画互相停止，玻璃样式不再同时执行隐藏的备用动画。 |
| 激活窗口 | 首击立即发送；后续 24ms 内保留最新目标，重复同目标去重；后来的最小化/关闭/组动作取消旧的待激活请求。 |
| 窗口状态更新 | 首个事件启动 16ms 合并计时，后续事件不再重启。 |
| 自动隐藏评估 | 输入/弹窗/模式变化立即评估；普通几何变化最多等一次 80ms 合并，不再无限延期。已计算的冲突结果不重复计算。 |
| 小幅显隐反转 | 最小时长从 70ms 降到 16ms，按剩余距离推进。 |
| Always 模式 | 清理停止计时器遗留的 temporaryRevealHold，避免旧 hold 状态阻止后续隐藏。 |
| 窗口预览 | 首次停留 220ms，切换已打开预览 75ms，返回可见的同一预览立即恢复；入场 90ms，使用 FrameAnimation 启动，移除固定 16ms 等待。 |
| 信息/音乐/温度详情 | 首次停留统一 220ms，入场 100ms；重返可见 popup 直接恢复，不重置首次停留。 |
| Stack 弹窗交接 | 进入 popup 停止关闭，离开 popup 且未回到卡片时重新启动关闭计时。 |
| 纯文字 tooltip | App 名称、托盘、状态标签、温度标签都不接收鼠标输入；关联公共文字提示入场/退出 70ms。 |
| 滚轮 | 不再丢弃 180ms 内的事件；按滚轮刻度/触控板像素累计，下一帧合并切换；方向反转清理未显示的旧方向。 |
| Stack 页面反馈 | 横向信息卡位移 160ms、淡入 120ms。 |
| 激活状态颜色 | 与 70ms 高亮节奏统一，移除独立写死的 150ms 状态色过渡。 |

保留 App 名称 180ms、预览/信息 popup 跨窗口关闭保护、配置保存和后台采样。未运行验证，实际帧率与全部交互仍由虚拟机人工确认。
