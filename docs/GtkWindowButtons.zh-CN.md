# GTK 原生三色窗口按钮

GTK 与 Qt 共用设置中的 **KOS window appearance（KOS 窗口外观）** 总开关，
以及 **Window button icons（窗口按钮图标）** 的“始终显示 / 悬停显示”选项。
无需单独安装或启用 GTK 样式。

- 开启窗口外观：同步 GTK 3/4 原生三色按钮样式及右侧“最大化、最小化、关闭”布局。
- 关闭窗口外观：恢复原 GTK 样式和布局，保留已记录的应用适配规则，重新开启时继续使用。
- 修改图标模式：GTK 原生按钮与 Qt/KWin 按钮采用相同配置。悬停模式只隐藏符号，保留三色圆点。
- 安装、升级执行窗口默认配置时同步 GTK；保留已经关闭总开关或改用其他装饰的用户选择。

绿色按钮使用 GTK 自带的最大化/还原，不进入全屏。GTK 应用需重启后读取更新的样式；
重新登录会同时应用原有 Qt 装饰切换与 GTK 样式。仅窗口控制按钮被修改，工具栏保持原主题。

标准 GTK 3 标题栏现在通过随项目安装的 `libkos-gtk-window-controls.so` 自动识别，
不需要登记应用名称。模块检查实际 `GtkHeaderBar`、可见的标准关闭按钮以及窗口映射状态：
确认存在原生按钮后，Wayland 使用窗口控制协议声明客户端绘制，XWayland 使用窗口属性通知 KWin。
KWin 停止该窗口的浮层、输入拦截和背景采样。按钮隐藏或移除时撤销声明，恢复原有浮层策略。
识别由 GTK 控件事件触发，不轮询进程、像素或标题栏，也不依赖 Remmina 等应用名单。

未知窗口继续使用浮层。GTK 4 不支持 GTK 3 模块加载方式，本轮没有宣称 GTK 4 自动识别；
它仍获得通用三色样式，但自动免浮层需要后续可靠的控件声明机制。
Edge/Chromium 自绘标题栏、没有标准标题栏的 GTK 窗口，以及不能加载宿主模块的 Flatpak
同样保留兜底。KWin 服务端装饰继续使用装饰器原生按钮。

安装与升级都会部署模块并同步现有总开关。首次安装模块或从旧版本升级后，完整注销登录一次，
让 Plasma 自动加载生成的 `plasma-workspace/env/kos-gtk-window-controls.sh`；不需要手动导出
环境变量。之后新启动的标准 GTK 3 应用自动参与识别。此脚本保留已有 `GTK_MODULES` 项，
重复同步不重复添加模块；关闭开关会恢复样式并移除受管理的启动配置，已经运行的应用需退出后重开，
会话环境的完全恢复在下次登录生效。用户原先关闭总开关的状态会在升级中保留。

`WindowSettings` 使用内置资源同步 GTK，不依赖源码目录。用户原有 CSS、其他 GTK 设置及
GSettings 布局会备份并在关闭时恢复；用户后续更改的无关配置会保留。不能写入配置时向设置页
报告错误，不把失败当作启用成功。受声明式管理的符号链接不会被覆盖。

旧版兼容性维护工具仍可添加或移除人工确认的规则；标准 GTK 3 自动识别不使用这些规则：

```sh
./tools/kosctl gtk-buttons adapt org.example.Application
./tools/kosctl gtk-buttons fallback org.example.Application
```

这不是另一套用户开关。安装/卸载低层样式命令仅供开发验证，不作为日常启用步骤。
所有项目安装、运行和验证只在虚拟机执行。测试入口与边界见[英文说明](GtkWindowButtons.md#vm-acceptance)。

Firefox 的标题栏需要单独的[原生适配](FirefoxWindowButtons.zh-CN.md)，登记后共用上述开关。

自动识别验收入口为 `tests/gtk-buttons/automatic-vm.py`，覆盖无应用规则的 Wayland/XWayland 窗口、
按钮隐藏/恢复、真实 Remmina，以及安装目录运行的全新安装和已有配置升级。
构建依赖增加 GTK 3 开发包和 Wayland scanner；`kosctl deps` 与 Nix 打包均包含所需依赖。
安装目录缺少模块时会明确失败，不会将仅安装样式报告为识别模块已启用。

### GTK 3 按钮外观

模块直接绘制标准 GtkHeaderBar 中已有的 GtkButton，保留 GTK 的点击行为和无障碍语义，不创建浮层。圆点使用与 KWin 装饰器相同的 14 像素尺寸、0.75 像素边框、颜色及符号比例；按钮点击区域至少 28 像素。绿色按钮在最大化和还原时切换双三角符号，并遵循统一的符号显示设置。关闭集成、移除托管样式后，绘制回调让回 GTK 默认外观。
