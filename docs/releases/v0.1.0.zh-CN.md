## 内容

首个核心桌面版：顶栏、Dock、启动器/搜索、通知、设置、平台/数据服务、KWin 特效和装饰器。
[PR #232](https://github.com/SuceV587/NextKde/pull/232)加入正式版源码选择、Installed/Source 分离、运行树备份/清理及单一最新维护策略。
[Issue #230](https://github.com/SuceV587/NextKde/issues/230)通过检测 shader API 修复，并修正 Dock 自动隐藏顺序。
[PR #234](https://github.com/SuceV587/NextKde/pull/234)整合日历 UI、计算器、天气、翻译、应用测试及 KWin 6.6/6.7/6.8 完整 SDK。

## 实际验收及范围纠正

Kubuntu/Ubuntu 26.10 x86_64 Wayland VM，Qt 6.11.2、KWin 6.7.5、Quickshell 0.3.0：
128 项核心/UI、20 项应用/PIM、25 项发布工具、322 项 Wayland 读回、64 项 GPU 检查。
通过默认**核心**安装、旧安装迁移、开发基线升级/重装回退、配置保留/备份恢复、重启插件加载、卸载恢复 Plasma。
发布后检查了真实默认 stable 核心安装。首版没有上一正式版可验回退。

应用构建/测试及日历视图/编辑器/待办关联、计算器键盘、天气夹具、真实 Open-Meteo 城市/48 小时/7 日预报已检查。
**未覆盖真实默认 `kosctl install apps`**，当时手工构建显式关闭 ListenFree，遗漏导致默认音频 SDK 构建问题发布。
20 项应用测试不能解读成默认安装器验收。

最终 6 项 CI 全过。KWin 6.6/6.8 仅完整 SDK 构建链接、离线/API 兼容，真实桌面为 6.7.5；容器 GPU 跳过项在 VM 补验。
全部项目验证在 VM/托管 CI。

## 安装和恢复

见[安装](../GettingStarted.zh-CN.md)、[NixOS](../nixos-quickstart.zh-CN.md)、
[备份/回退](../Releasing.zh-CN.md#备份与回退)。显式历史版本：

```sh
./tools/kosctl update v0.1.0 &&
./tools/kosctl install &&
./tools/kosctl start
./tools/kosctl version
```

KWin 需注销登录/重启。部署不是事务，运行树/配置备份不是完整系统回滚。
首版无上一正式版可推荐；恢复兼容旧配置前停相关服务，完整恢复依靠系统备份/VM 快照。
