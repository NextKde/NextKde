## Content

Initial core desktop release: bar, Dock, launcher/search, notifications, Settings, platform/data
services, KWin effects and decoration. [PR #232](https://github.com/SuceV587/NextKde/pull/232)
introduced stable source selection, separate Installed/Source reporting, runtime backups and cleanup,
and the one-current-release policy. [Issue #230](https://github.com/SuceV587/NextKde/issues/230)
was addressed with KWin shader API detection; Dock auto-hide ordering was also corrected.
[PR #234](https://github.com/SuceV587/NextKde/pull/234) integrated Calendar UI, Calculator and Weather,
translations, app tests and full KWin 6.6/6.7/6.8 SDK compatibility jobs.

## Actual validation and correction of scope

Kubuntu/Ubuntu 26.10 x86_64 Wayland VM, Qt 6.11.2, KWin 6.7.5, Quickshell 0.3.0:
128 core/UI tests, 20 app/PIM tests, 25 release-tool tests, 322 Wayland readback checks and
64 GPU checks. Default **core** installation, legacy migration, upgrade/reinstall rollback from
a development baseline, configuration preservation/backup recovery, reboot plugin loading and
uninstall recovery to Plasma passed. The actual published default stable core install was checked
after publication. This first release had no previous stable version for rollback acceptance.

App builds/tests and interactive Calendar views/editor/Todo link, Calculator keyboard input,
fixture Weather and real Open-Meteo location/48-hour/seven-day forecasts were checked.
**The actual default `kosctl install apps` installer was not covered**: the app build explicitly
disabled ListenFree. That omission allowed an unwanted default audio SDK build to ship.
Do not interpret the 20 app tests as default-installer acceptance.

All six final CI jobs passed. KWin 6.6 and 6.8 results establish full SDK build/link, offline/API
compatibility only; real desktop runtime acceptance was KWin 6.7.5. Container GPU skips were
covered in the VM. All project verification ran in VM/hosted CI.

## Known issues and follow-up

v0.1.0 default apps installation enables ListenFree and its expensive SDK build. Its source tree
also contains process screenshots/logs excluded from the release archive. These are corrected in
[v0.1.1](v0.1.1.md), together with shallow source selection and Settings ownership safeguards.
The old tag/source/evidence remain immutable. Current-tree cleanup does not erase Git history.

Not fully accepted: native Debian 13; complete NixOS deployment; other architectures/X11;
actual spatial-model download/inference; full ListenFree/other optional apps/lockscreen; SELinux
installation; multi-user isolation of shared system plugins; cross-schema downgrade.
Calculator currency conversion uses a dated offline reference, not live exchange rates.

## Installation and recovery

See [installation](../GettingStarted.md), [NixOS](../nixos-quickstart.md) and
[backup/rollback policy](../Releasing.md#backups-and-rollback). Explicit historical selection:

```sh
./tools/kosctl update v0.1.0 &&
./tools/kosctl install &&
./tools/kosctl start
./tools/kosctl version
```

Then logout/login or reboot for KWin. Deployment is not atomic; runtime/config backups are not a
complete system rollback. The original release has no prior stable to recommend. Stop relevant
services before restoring compatible old config; full recovery needs a system backup/VM snapshot.
