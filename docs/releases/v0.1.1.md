# NextKDE v0.1.1

[简体中文](v0.1.1.zh-CN.md)

Patch release for default application installation and documentation.
The immutable tag and attached exact-commit validation are published on
[the v0.1.1 Release](https://github.com/SuceV587/NextKde/releases/tag/v0.1.1).
A version file or this page alone does not prove publication or acceptance.

## Changes

[PR #237](https://github.com/SuceV587/NextKde/pull/237):

- `kosctl install apps` and standard app presets build Calendar, Calculator, Todo and Weather.
  ListenFree and its audio SDK require explicit `--with-listenfree`. An old enabled CMake cache
  is reset to OFF for the default path; unselected audio dependencies/SDK are ignored.
- Standard installation preserves audio MIME associations and legacy music registrations.
  Explicit audio opt-in keeps its dependency checks and migration path.
- Apps installation no longer overwrites only `main.qml` in core Settings. Core owns its complete
  Settings/shared QML runtime; apps-only installation works without core Settings.
- Remove 482 process screenshot/log files (about 541 MiB) from the current tree. Required product
  assets and third-party notices remain. Historical Git objects remain; default shallow clones and
  shallow ref selection avoid downloading the removed history. Existing full clones do not shrink.

Documentation is English by default with Chinese companions for installation, development,
contribution/context, release policy/notes, appearance/window/wallpaper/theme and NixOS entry points.
Redundant architecture overviews and historical plans/audit diaries are consolidated into current
contracts. AI contributor guides state ownership, source entry points, failure behavior and VM-only
verification. v0.1.0 notes now distinguish core acceptance from the missed default app installer.

## Install and upgrade

Prepare [dependencies](../GettingStarted.md), then:

```sh
./tools/kosctl update &&
./tools/kosctl install &&
./tools/kosctl start
./tools/kosctl install apps
./tools/kosctl version
```

Default `update` selects GitHub Latest, so this reaches v0.1.1 only after it is published as Latest.
An explicit `update v0.1.1` requires the published tag. KWin changes need logout/login or reboot.
Optional ListenFree: `./tools/kosctl install apps --with-listenfree` with its additional dependencies.

## Acceptance and limits

Publication requires all six CI jobs on the final release commit, Tag identity, and VM default core/
apps installation, upgrade from v0.1.0, compatible reinstall rollback, retained preferences/backups,
reboot plugin loading and live Shell checks. Exact results, environment, source digest and post-publish
default installation are attached to the Release. The default app command must be executed directly.

KWin 6.6/6.7/6.8 SDK builds are distinct from actual runtime acceptance on KWin 6.7.5.
Do not infer native Debian/NixOS, other architectures/X11, full optional audio/lockscreen or spatial
model inference coverage. Calculator rates remain a dated offline reference. System plugins are
shared across users; installation is not an atomic transaction or an isolated multi-user deployment.
No new configuration/database schema migration is introduced by this patch; cross-schema downgrade
is still unverified. Follow [backup and rollback](../Releasing.md#backups-and-rollback), stop services
before restoring old-format data, and keep a system backup/VM snapshot for complete recovery.
Only the latest official release is maintained; old tags remain immutable.
