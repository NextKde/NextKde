## 改动

[PR #237](https://github.com/SuceV587/NextKde/pull/237)：

- `kosctl install apps` 和标准预设仅构建日历、计算器、待办、天气；ListenFree/音频 SDK 需显式 `--with-listenfree`。
  旧 ON 缓存默认重置 OFF，不选音频时忽略其依赖/SDK。
- 默认保留音频 MIME 及旧播放器注册；显式音频保留依赖检查与迁移。
- 应用安装不再只覆盖核心 Settings 的 `main.qml`，完整 Settings/共享 QML 由核心管理；应用专用安装无核心也可用。
- 当前树删除 482 个过程截图/日志（约 541 MiB），保留产品资源及第三方说明。历史 Git 对象仍存在；
  默认浅克隆及浅引用选择避免下载旧历史，已有完整克隆不会自动缩小。

文档默认英文，安装、开发、贡献/上下文、发布流程/说明、外观/窗口/壁纸/主题、NixOS 入口提供中文对照。
重复架构、历史方案/审计流水账合并为当前契约。AI 开发指南说明所有权、源码入口、故障行为和 VM-only 验证。

## 安装升级

先准备[依赖](../GettingStarted.zh-CN.md)：

```sh
./tools/kosctl update &&
./tools/kosctl install &&
./tools/kosctl start
./tools/kosctl install apps
./tools/kosctl version
```

默认 update 选择 GitHub Latest，发布为 Latest 后才到 0.1.1；显式 `update v0.1.1` 需要已发布 Tag。
KWin 更新需注销登录/重启。可选 ListenFree：`./tools/kosctl install apps --with-listenfree` 并准备额外依赖。

## 验收与限制

发布门槛为最终提交 6 项 CI、Tag 身份、VM 默认核心/应用安装、从 0.1.0 升级、兼容重装回退、偏好/备份、
重启插件、真实 Shell。精确结果、环境、源码摘要、发布后默认安装附 Release，应用入口必须直接执行。

KWin 6.6/6.7/6.8 SDK 与真实 KWin 6.7.5 运行验收分开。
不据此声称 Debian/NixOS 原生、其他架构/X11、完整可选音频/锁屏或空间模型推理验收。
计算器汇率仍是注明日期离线参考。系统插件多用户共享，安装不是事务，也非隔离多用户部署。
此补丁未引入配置/数据库 schema 迁移，跨 schema 降级仍未验证。
按[备份与回退](../Releasing.zh-CN.md#备份与回退)停服务恢复旧格式数据，完整恢复保留系统备份/VM 快照。
只维护最新正式版，旧 Tag 不变。
