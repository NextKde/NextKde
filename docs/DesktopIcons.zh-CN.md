# 桌面图标间距

[English](DesktopIcons.md)

## 桌面快捷方式

在启动台中右键应用图标并选择 **发送到桌面**，会在 XDG 桌面目录创建一条以该应用
`.desktop` 文件命名的符号链接。链接指向已安装的 desktop entry，应用更新后快捷方式
自动跟随；启动台的自定义图标通过文件名匹配继续生效，自定义显示名称不会写入快捷方式。

重复发送不会覆盖桌面上的同名文件或链接，启动台会提示“桌面已存在该快捷方式”。
桌面目录不存在或不可写时操作失败并发送通知；平台守护进程不可用时无法完成操作，
只会记录失败，因为 QML 没有写桌面文件的回退路径。创建成功后 Shell 请求
`desktop.refresh`，即使 data-service 的目录 watcher 未启动，新图标也会出现。
打开、重命名、剪切/移动和移入回收站继续使用现有桌面文件操作；重命名、移动和删除
作用于快捷方式链接本身，不会修改已安装的 `.desktop` 文件。

## 图标大小

桌面空白处右键 → **图标大小**，可选 **极小**、**小**、**中**、**大**。四档的逻辑像素
分别为 32、40、56、72；实际图形尺寸在对应值上加 12，因此“极小”的图标图形为 44。
文件名标签使用桌面字体，图标大小只改变图形和格子尺寸，不改变标签字号。设置保存在
`deskcenter-desktop-files.ini` 的 `DesktopFiles/iconSize`，已有值保持不变。

图标大小和图标间距相互独立。尺寸按逻辑像素随系统缩放，“极小”适合在高分辨率屏幕上
显示更多图标。网格会优先用剩余高度多排一行，并至少保留 3px 行间距；只有无法容纳时才
留下底部余量。多出来的一行会从当前对齐边缘开始填列，另一侧的列可能较短。紧凑和更紧凑间距仍使用
108/96 的列宽下限，因此“极小”档在这两种间距下主要增加行数；列数是否增加取决于实际
字体行高和可用宽度。

## 快捷方式对齐

桌面空白处右键 → **整理方式**，在排序项下方选择 **左对齐** 或 **右对齐**；默认右对齐。
对齐发生在桌面文件区域内：右对齐靠文件区右缘，左对齐靠文件区左缘（小组件仍占用
其保留列）。设置保存在 `deskcenter-desktop-files.ini` 的
`DesktopFiles/shortcutAlignment`，旧配置默认右对齐。

切换后网格按列重新映射：槽位仍然是先填满一列再换下一列，左对齐从文件区左缘开始，
右对齐从右缘开始。框选、拖动、插入位置和文件夹合并使用同一套映射。

## 复制与拖入文件

在桌面按 Ctrl+V 或右键**粘贴**，可以接收在其他应用中复制的本地文件列表。
平台服务先读取 Qt 剪贴板；当后台守护进程看不到其他应用的 Wayland 选区时，
会回退到 `wl-paste --type text/uri-list`。该回退按**复制**处理，因此在其他应用
剪切的内容会以复制方式粘贴，而不是移动。复制的图片位图（浏览器或截图）没有
文件路径，会以 `剪贴板图片 <时间戳>.png` 保存到桌面目录，并放置到当前输出。

拖拽只接受**本地文件 URL**，落点必须在桌面文件区（右侧、组件列之后），
通过 `file.transfer` 按提议的复制/移动动作执行。远程 URL 和纯位图拖拽会被拒绝；
隐藏点文件不显示。桌面目录来自 `xdg-user-dir DESKTOP`，必须可写。目录会递归复制；
平台会限制并发复制任务（总共 32 个，每客户端 8 个）。

## 聚合显示

聚合显示是内置桌面组件（`groups`），和时钟、天气一样由组件系统管理。它默认隐藏，
升级不会改变原有桌面。进入桌面组件编辑模式后从 **组件** 中启用，或右键桌面选择
**聚合显示**；隐藏后恢复普通文件图标。

组件锚定在桌面网格右上角，默认 **2×3**（约 370 × 560 逻辑像素），其他组件继续
留在左侧流式布局。支持的跨度为 **2×2、2×3、3×2、3×3**；最小为 2×2，因为标题栏
加四个类型标签页至少需要约 222 px，且单列内容区放不下成员格。屏幕太矮、连 2×2
都放不下时保留普通文件图标，不显示残缺的组件。它与桌面组件使用同一套表面后端：玻璃外观下由合成器绘制玻璃，
Material 下使用色调面板。它显式关闭“彩色卡片”组件风格以保留该材质，并和组件卡片
一起加入同一个窗口级模糊区域。移动和缩放使用组件编辑模式；组件布局按输出保存
位置和跨度。用户最后一次**主动点击**的类型全局保存于
`DesktopFiles/groupSelectedCategory`；某个屏幕没有该类型成员时只在本地回退到第一个
非空类型。组件不参与快捷方式对齐、框选、拖动排序或**重置图标顺序**。

类型和顺序固定：

| 标签页 | 成员 |
| :-- | :-- |
| 快捷方式 | `.desktop` 启动器 |
| 图片 | 图片文件 |
| 目录 | 真实文件夹 |
| 文件 | 其余全部，包括 PDF、文本、代码以及未知或以后新增的类型 |

四个标签页固定不变，便于形成操作习惯。每页显示成员数量；空类型会变暗且不可选，
组件自动回退到第一个非空类型。右侧以可滚动的网格显示当前类型的成员：单击成员
会以与普通图标层相同的填充高亮选中，双击打开。成员图标跟随桌面图标大小设置
（小/中/大），网格格子尺寸和标签字号也随之调整。

组件标题栏的查询按钮会打开一个只有输入框的气泡，只按名称筛选左侧当前选中的
类型。Esc 或点击气泡外部只会关闭气泡，筛选仍然生效，避免关闭瞬间内容变化；
手动清空输入框才恢复完整类型。筛选生效时查询按钮保持高亮。

聚合组件只是同一份桌面快照的投影，不会改写已保存的槽位。右键成员会打开与普通
桌面相同的文件菜单，可通过同一套平台操作重命名、复制/剪切、打开方式或移到回收站；
由于普通图标层被隐藏，重命名使用卡片内的内联编辑器。成员名称遵循“显示文件扩展名”
设置，自定义文件夹保留颜色和表情。组件在某个输出显示时，该输出会隐藏普通文件
图标；因此向真实文件夹拖文件前需要先隐藏组件，“目录”页只是索引，不替代文件夹的
拖放目标。组件和其他桌面组件一样只出现在活动输出上，其他输出继续显示文件图标。

`DesktopGroups.mjs` 负责类型映射和标签页图标；`DesktopGroupsContent.qml` 是组件
内容；`DesktopGroupMemberIcon.qml` 解析成员图标；`WidgetLayout.mjs` 负责右上角
锚定放置、2×2 最小跨度以及 2×3/3×2/3×3 跨度限制。`kos-deskcenter.group-by-type` 覆盖纯映射与 QML 接线，
`kos-deskcenter.widget-layout` 覆盖锚定放置和跨度限制，
`kos-deskcenter.group-by-type-runtime` 用隔离的假数据加载真实内容。它们都不能替代
VM 中对玻璃材质、组件编辑模式、标签页重排和多显示器行为的视觉验收。

## 桌面表面归属

`DeskCenterWindow.qml` 在各输出上承载组件、图标及其右键菜单。它使用
`dock` layer-shell namespace，让 KWin 的普通窗口关闭、移动快捷键和显示桌面隐藏逻辑排除桌面组件，
同时避免透明组件层被当成壁纸。原生概览只捕获一个 Desktop 窗口，因此只有壁纸表面使用
`desktop`。Glass 将壁纸、组件和 Dock 合成为原生概览的桌面背景，让它们一起随桌面预览缩放。
原生 Slide 切换虚拟桌面时，Bridge 仅取消 Below 层 Quickshell Dock 表面的特效置顶，
让桌面内容始终位于应用下方；Top/Overlay 面板保留正常置顶，不修改概览类型或桌面归属。
`tests/desktop-slide/run-vm.py` 用真实 DeskCenter、覆盖它的应用及正常面板检查连续切换。
仅在完整预览可用时抑制重复的原生面板缩略图。
保留 Bottom 层，降到 Background 可能被 Plasma 盖住。平台托管的
`kwin/window-bridge.js` 中，`installDesktopStack()` 将已有 Below 层表面固定为
壁纸 < 组件 < 台前调度条，不依赖台前调度开关或映射先后。它不修改可见性、
虚拟桌面归属，也不重建窗口。

玻璃特效只接受明确声明了非空内容区域的 Desktop 类型 Quickshell 表面及 Below 层 Quickshell Dock，继续排除壁纸和
旧协议中表示整窗模糊的空区域。DeskCenter 保持桌面内容材质，Top/Overlay 面板保持 Dock 材质。
`kos-deskcenter.desktop-stack` 覆盖映射排列、重入层序信号、首帧就绪前层序及概览壁纸候选；
`kos-glass.desktop-blur` 覆盖表面分类和显式声明边界。
`kos-ui.desktop-overview` 在私有 KWin 中加载两个真实 Shell 表面，检查两种映射顺序下原生
`DesktopBackground` 的选择，并操作桌面关闭/移动及显示桌面；它不能替代概览视觉验收。

在 VM 验收 Plasma 和 Shell 各自管理的壁纸、原生概览/桌面网格、多输出、显示桌面、
桌面关闭/移动快捷键，以及概览退出前后的组件玻璃。源码/SDK 检查不能证明视觉验收通过。

## 组件定位与缩放

桌面编辑模式下，拖动组件到空网格，或拖动右下角手柄缩放。普通组件限制在 1×1–2×2；
天气组件还可扩展到 3×1 和 3×2；聚合显示使用 2×2 到 3×3 四档。手柄的上限和下限
分别取自各组件声明的跨度，因此按下手柄不会把卡片立即缩成更小的尺寸。
落点预览区分空位与占用；移动一个组件会固定其他可见组件的位置。
`DeskCenterConfigService` 在既有尺寸/顺序设置旁保存网格跨度和按输出区分的位置，兼容旧 small/medium/large 值。
布局先预留已保存位置，再填空位并按需扩展组件列；冲突或越界时仅在当前输出投影中回退排布，
不改写原坐标。短屏临时压缩组件，桌面文件区域避开组件占用列。组件扩展始终预留至少一列文件/拖入区域，
并按现有文件数量增加预留，最多保留原四列组件布局的文件容量。缩放遇到占用或越界时拒绝提交，
不会重排相邻组件。移动仅持久化当前组件及尚未保存位置的邻居；其他临时回退坐标只存于
当前网格尺寸的内存投影中，保留其原始保存位置。

`WidgetLayout.mjs` 负责排布、吸附和碰撞判断；`WidgetResizeHandle.qml` 预览跨度、松手提交，缩放与移动互斥。
拖动直接更新卡片的 `x/y`，按住期间禁用位置动画。卡片同时是原生玻璃的几何锚点；仅改变 `Translate`
不会触发 `SurfaceShape` 几何同步。落点吸附直接读取当前坐标，不重复叠加拖动偏移；松手后动画吸附至有效格或原位。
Repeater 使用按组件 ID 增量维护的 `ListModel`。位置/尺寸快照只更新布局数据，不替换组件实例；
显隐和顺序变化只移除、插入或移动受影响的行，移动其他组件时保留表盘及其他组件内容。
时钟表盘和倒计时共用页面选择进度动画，再按当前高度计算页面位置；仅高度变化时，
隐藏的倒计时必须留在表盘下方，不能重新播放滑入/滑出动画。编辑模式下，时钟的
“指针/数字”控件只切换表盘，不替换倒计时。`DeskCenterConfigService` 将选择保存为
`analog` 或 `digital`，缺失或无效值回退为指针。两种表盘共用时间源和外观令牌；
数字时钟保留普通圆角卡片，指针时钟使用花瓣轮廓。
`kos-deskcenter.widget-layout` 覆盖几何和旧尺寸兼容；`kos-ui.widget-resize` 覆盖指针输入、抬起动画结束后继续拖动时的
玻璃锚点几何、布局保存与排序时卡片/表盘实例保留，以及 Shell 重启后的持久化。
在具有所需图形环境的 VM/CI 中运行，真实界面截图仍需 VM 审阅。

## 间距与几何

桌面空白处右键 → **图标间距**，可以独立于图标大小选择：

- **宽松**：保留较大的格子与空隙，适合少量文件。
- **紧凑**：减少格子留白与行列间距，仍保留两行文件名及框选空隙。
- **更紧凑**：进一步缩短横向距离，较长的名称更容易换行或省略。

切换间距不会更改图标大小、系统缩放或桌面文件，也不改变左侧小组件的布局。文件名保持两行上限，行高取自实际字体；字号增大时，格子高度会相应增加，避免文字压住下一行。设置保存在 Quickshell 的 `deskcenter-desktop-files.ini` 的 `DesktopFiles/iconSpacing`，旧配置默认使用宽松。

桌面组件通过 `DesktopGridMetrics.mjs` 统一计算格子、空隙和内容区域。紧凑模式使用固定的目标格子宽度，不再继承外层均分后又叠加间距的列宽。选中背景、鼠标区域和框选区域使用相同的内容边界，格子之间继续属于桌面背景。

可用位置变化时保留仍有效的手工位置，补入新增可见项目，并将超出边界的项目重新安排到空位。较小的可用区域只能显示其容量允许的项目，扩大后会重新纳入其余项目，不修改或删除实际文件。
拖动期间发生的容量变化会延后到拖动结束处理，保留仍有效的手工位置。

以可用区域约 987 × 947 逻辑像素、小图标和 16px 字体行高为例，宽松模式有 7 × 8 = 56 个位置，紧凑模式有 8 × 9 = 72 个位置，更紧凑模式有 9 × 9 = 81 个位置。实际容量取决于屏幕缩放、字体、小组件和 Dock 占用，不固定承诺数量。

验证统一通过 `./tools/run-tests.sh --all`：

- `kos-deskcenter.density-metrics` 检查容量、三档尺寸、两行字体边界与扩缩后的布局。
- `kos-deskcenter.density-runtime` 在隔离的 Quickshell 实例中加载实际组件，检查切换后新增图标可见、框选空隙不误选、单图标选择和恢复宽松布局。

测试使用虚拟项目与隔离状态目录，不读写真实桌面文件。
